# 快速上手

本章带你从零开始，把你自己的本体文件夹显示在地图上，再和 Claude Code、Codex 等编码智能体一起完成第一个任务。你可以从桌面应用开始，也可以从浏览器开始。

## 选择应用还是浏览器

- **应用** 是完整的产品。可以从 [ontologyatlas.com](https://ontologyatlas.com/zh/download/) 下载。macOS 版面向 Apple Silicon，已签名并经过公证。Windows x64 版是未签名的测试版，因此运行前 SmartScreen 可能会弹出警告。
- **浏览器版** 无需安装。它会立即打开一张示例地图；在 Chrome 或 Edge 中，还可以打开你磁盘上的文件夹。Firefox 等不支持文件夹访问的浏览器只显示示例和应用的下载链接。

有些功能只有应用才有：在多次使用之间记住你的文件夹、Git 历史、地图旁的智能体对话、模型密钥，以及一键把 MCP 服务器注册到你的编码智能体。

## 查看示例地图（浏览器）

没有打开文件夹时，浏览器会显示一份标有 **暂为示例** 的示例。你可以在两个示例之间切换：

- **网店**：商品、订单、会员和配送。用大家都熟悉的名称来学习如何阅读地图。
- **本应用的代码**：Ontology Atlas 仓库真实的本体，由人和智能体共同构建和维护。

卡片上会显示示例的规模：概念、关系和领域各有多少。点击一个概念：通往它所依赖的概念和使用它的概念的连线会亮起，并在面板中列出它们的名字。其余内容请看 [读懂地图](/guide/reading-the-map)。

## 打开或创建本体文件夹

### 在应用中

没有打开文件夹时，应用提供四种开始方式：

- **从代码项目开始**：选择你的代码文件夹。Atlas 会询问 **在这个代码文件夹中创建本体文件夹？** 并显示路径。按下 **创建**，它就会在那里新建一个 `atlas` 文件夹，不会动你的代码。如果应用中已有可用的编码智能体，它接着会读取代码并写出第一张地图。
- **在主目录中创建**：在你主目录下的 `Ontology Atlas` 中新建一个文件夹，不弹出选择器。
- **打开文件夹**：选择一个现有的 Markdown 文件夹。
- **从空文件夹开始**：选择一个空文件夹，Atlas 会往里面添加起步用的 Markdown 文件和智能体设置。

两种“创建”方式都会先问 **这个文件夹要放什么？**：**文档 Wiki**、**代码地图** 或 **两者都要**。另一部分以后可以在设置中补上。

### 在浏览器中

按下 **打开文件夹**。一段简短的说明会解释接下来会发生什么，然后提供 **选择现有文件夹** 或 **用空文件夹重新开始**。选好之后，浏览器会请你授予访问权限。这项权限让页面能够在你的电脑上读取该文件夹；不会上传任何内容。

### Atlas 如何处理文件夹

任何 Markdown 文件夹都可以。frontmatter 中带有 `kind:` 一行的文件会成为地图上的一个概念；其他 Markdown 文件仍是普通文档。打开文件夹不会移动或重命名任何文件。目录布局见 [本体文件夹](/guide/vault-structure)。

## 和编码智能体迈出第一步

当你的编码智能体在执行任务之前先读一遍地图时，地图最能发挥作用。在应用中：

1. 打开 **智能体**，再打开 **MCP** 标签页。
2. 为你的智能体按下 **连接**。对于 Claude Code，Atlas 会在文件夹中写入 `.mcp.json`；对于 Codex，会写入 `.codex/config.toml`。列表中还有 Cursor 和 Antigravity。
3. 退出并重新打开该智能体。
4. 向智能体说明你的下一个任务，例如：“在修改结算功能之前，先读取它涉及的 Atlas 概念，告诉我有哪些地方依赖它。”

智能体在需要时会在你的电脑上启动 Atlas MCP 服务器。该服务器不会打开任何网络端口。每种智能体的连接方式、浏览器的情况以及故障排查，请看 [连接编码智能体](/guide/connect-agent)。

如果你的文件夹里还没有任何概念，可以让智能体根据你的代码起草：[从代码构建第一张地图](/guide/from-your-repo)。
