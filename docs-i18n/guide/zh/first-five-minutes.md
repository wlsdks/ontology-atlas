# 快速上手

本章带你从零开始，把你自己的本体文件夹显示在地图上，再和 Claude Code、Codex 等编码智能体一起完成第一个任务。你在桌面应用中完成这些步骤。

## 获取应用

可以从 [ontologyatlas.com](https://ontologyatlas.com/zh/download/) 下载。macOS 版面向 Apple Silicon，已签名并经过公证。Windows x64 版是未签名的测试版，因此运行前 SmartScreen 可能会弹出警告。

应用会就地读取你的文件夹，下次打开时无需再次授权就能重新打开同一个文件夹。Git 历史、地图旁的智能体对话、保存在系统凭据库中的模型密钥，以及一键把 MCP 服务器注册到你的编码智能体，也都在应用里。网页不会打开你的文件夹：ontologyatlas.com 只负责介绍 Atlas 并提供应用下载。

Linux 和 Intel Mac 没有对应的应用。这种情况下，可以看看下面的示例地图，或者在源码检出中运行 MCP 服务器：[从源码检出连接](/guide/connect-agent#connect-from-a-source-checkout)。

## 查看示例地图

安装之前，可以在 [示例地图](https://ontologyatlas.com/zh/sample/) 中看到 Atlas 画出的地图。它是一家网店：商品、订单、会员和配送，名称人人都熟悉。示例是只读的，不会打开任何文件夹。

点击一个概念，它与所依赖的概念、使用它的概念之间的连线都会亮起，面板中也会列出这些概念的名字。其余内容见 [读懂地图](/guide/reading-the-map)。在应用中，Atlas 会用你文件夹里的 Markdown 文件，以同样的方式画出你自己的代码。

## 打开或创建本体文件夹

没有打开文件夹时，应用提供四种开始方式：

- **从代码项目开始**：选择你的代码文件夹。Atlas 会询问 **在这个代码文件夹中创建本体文件夹？** 并显示路径。按下 **创建**，它就会在那里新建一个 `atlas` 文件夹，不会动你的代码。如果应用里已经有可用的编码智能体，智能体接着会读取代码，写出第一张地图。
- **在主目录中创建**：在你主目录下的 `Ontology Atlas` 中新建一个文件夹，不会弹出文件夹选择器。
- **打开文件夹**：选择一个现有的 Markdown 文件夹。
- **从空文件夹开始**：选择一个空文件夹，Atlas 会往里面添加起步用的 Markdown 文件和智能体设置。

两种“创建”方式都会先问 **这个文件夹要放什么？**：**文档 Wiki**、**代码地图** 或 **两者都要**。另一部分以后可以在设置中补上。

### Atlas 如何处理文件夹

任何 Markdown 文件夹都可以。如果文件的 frontmatter（顶部信息块）里有 `kind:` 这一行，它就会成为地图上的一个概念；其他 Markdown 文件仍是普通文档。打开文件夹不会移动或重命名任何文件。目录布局见 [本体文件夹](/guide/vault-structure)。

## 和编码智能体迈出第一步

编码智能体在动手做任务之前先读一遍地图，地图才最能发挥作用。在应用中：

1. 打开 **智能体**，再打开 **MCP** 标签页。
2. 为你的智能体按下 **连接**。对于 Claude Code，Atlas 会在文件夹中写入 `.mcp.json`；对于 Codex，会写入 `.codex/config.toml`。列表中还有 Cursor 和 Antigravity。
3. 退出并重新打开该智能体。
4. 向智能体说明你的下一个任务，例如：“在修改结算功能之前，先读取它涉及的 Atlas 概念，告诉我有哪些地方依赖它。”

智能体在需要时会在你的电脑上启动 Atlas MCP 服务器。该服务器不会打开任何网络端口。各个智能体的连接方法、从源码检出连接的方法和故障排查，见 [连接编码智能体](/guide/connect-agent)。

如果你的文件夹里还没有任何概念，可以让智能体根据你的代码起草：[从代码构建第一张地图](/guide/from-your-repo)。
