# 数据、隐私与安全

本章说明使用 Ontology Atlas 时你的数据存放在哪里、哪些内容会在什么时候离开你的电脑、通过 MCP 连接的编码智能体处在什么位置，以及如何确认你下载的应用正是我们构建的那一个。这里的每一条说法都可以在公开的源码中核实。

## 简而言之

- 你的本体是你所选文件夹中的普通 Markdown。Atlas 不会上传它。
- Atlas 没有后端服务器，没有账号，也没有遥测。
- 应用只通过下面列出的途径连接互联网，其中大多数只在你按下某个按钮时才会发生。
- 你连接的编码智能体是一个独立的程序。它可能会把你的提示词和它读取的内容发送给它自己的服务商，Atlas 既看不到，也无法记录这些流量。

## 留在你电脑上的内容

- **本体文件夹。** 这些 Markdown 文件是唯一的事实来源。即使删除应用，文件夹依然还在，任何编辑器或脚本都能继续读取它。
- **文件夹中的 `.ontology-atlas/`。** 存放文件夹设置和下文提到的传输日志。这个文件夹默认不进入 Git。
- **应用的搜索索引。** 在应用中默认开启。它根据文件夹中的文件构建，保存在电脑的缓存文件夹里，从不发送到任何地方。可以在设置的 **隐私 · 数据** › **保存在这台电脑上的内容** 中关闭或删除它。
- **模型服务商的 API 密钥**（仅限应用），保存在操作系统的凭据存储中，例如 macOS 钥匙串。浏览器版完全不接受密钥。
- **少量偏好设置**，例如最近使用的文件夹列表。浏览器只保存你打开过的文件夹的句柄，方便下次直接打开。

Atlas 只读取你选择的文件夹。读取文件夹时，它会跳过以点开头的文件和文件夹，例如 `.env` 和 `.git/`。

## 可能离开你电脑的内容

应用在设置的 **隐私 · 数据** › **外部传输** 中列出了每一条外发途径。它们是：

| 途径 | 何时发生 | 发往 | 是否包含文件夹内容 |
|---|---|---|---|
| 检查更新 | 自动，可关闭 | ontologyatlas.com | 否 |
| 下载更新 | 你按下按钮时 | github.com | 否 |
| 模型服务商 | 你按下按钮时 | Anthropic、OpenAI 或 Google API | 你发送的内容 |
| 本地模型服务器 | 你按下按钮时 | 你填写的地址 | 你发送的内容 |
| 外部模型审阅 | 你按下按钮时 | api.typesafe.ai | 你发送的内容 |
| 编码智能体安装 | 你按下按钮时 | nodejs.org、npm 仓库 | 否 |
| ACP 适配器包 | 你按下按钮时 | npm 仓库、PyPI | 否 |
| 读取 GitHub PR 描述 | 你按下按钮时 | api.github.com | 否 |
| Git 推送、拉取和获取 | 你按下按钮时 | 你的 Git 远程仓库 | 你发送的内容 |
| 你添加到文件夹的 MCP 服务器 | 智能体使用它们时 | 它们各自的地址 | 由智能体发送 |
| 编码智能体 | 智能体工作时 | 智能体自己的服务商 | Atlas 看不到 |

Atlas 发起的每一次模型调用，包括对本地模型服务器的调用，都会写入文件夹中的 `.ontology-atlas/llm-audit.jsonl`。自动检查更新由设置 › **关于** › **自动检查更新** 控制。

浏览器版只从 ontologyatlas.com 加载网站自身的文件。它在你的电脑上读取你的文件夹，从不上传。

## 编码智能体与 MCP

Atlas MCP 服务器不是一个常驻运行的服务。你的编码智能体在需要时才在你的电脑上启动它，通过标准输入输出（stdio）与它通信，会话结束时再把它停掉。它不打开任何网络端口，也不发出任何网络请求。

智能体本身则是另一回事。Claude Code、Codex、Cursor 等智能体会把你的提示词和它们读取的文件发送给各自的服务商。这些流量属于智能体，遵循智能体自己的设置，不会出现在 Atlas 的日志中。

由谁批准一次写入，取决于智能体在哪里运行：

- **在应用的智能体对话中**，每一次文件编辑和每一次 Atlas 写入都会等你按下 **仅允许一次** 或 **拒绝**，除非你为该文件夹开启了 **自动批准**。Shell 命令、删除操作以及文件夹以外的路径始终会询问。
- **通过 MCP 连接的智能体** 在它自己的终端或编辑器中运行，写入时遵循该工具的权限规则，而不是 Atlas 的规则。

无论哪种情况，改动都是你文件夹中的一份 Markdown diff，你可以在 Git 中审查或撤销它。

## 核验你下载的应用

- **macOS**：应用使用 Apple Developer ID 签名，并经过 Apple 公证。每个构建在发布之前，发布流程都会验证已签名的磁盘映像和安装后的应用；没有通过验证的构建不会发布。应用内更新同样经过签名。
- **Windows x64 测试版**：安装程序未签名，因此 SmartScreen 可能会显示“未知发布者”警告，受管理的电脑也可能会阻止它。发布之前，每个构建都要经过 Microsoft Defender 扫描，并实际做一次静默安装和启动。
- **Linux**：目前还没有应用。请使用浏览器版，或者从源码运行 CLI 和 MCP 服务器（[CLI](/guide/cli)）。

[发布页面](https://github.com/wlsdks/ontology-atlas/releases) 上的安装包（`.dmg`、`.exe`）和 MCP 包（`.mcpb`）旁边都有一个 `.sha256` 文件。把其中的值和你下载的文件算出的校验和对比一下。

在 macOS 上：

```sh
shasum -a 256 <file>
```

在 Windows 上，请在 PowerShell 中运行：

```powershell
Get-FileHash <file> -Algorithm SHA256
```
