# 从代码构建第一张地图

本章为你的仓库构建第一个代码库本体：你的代码所实现的领域、能力和元素，以及它们之间的关系。Claude Code 或 Codex 等编码智能体通过 MCP 读取代码并提出地图草案，由你审查；只有你批准的内容才会写入。

## 谁负责什么

Atlas 本身不会把代码变成含义。智能体读取代码，带着依据提出概念和关系，再把你接受的那些以 Markdown 形式写进本体文件夹。你的代码只读不改。

对仓库的扫描结果是依据，而不是答案。`analyze_repo_structure` 和 `infer_imports` 不写入任何内容。文件夹名或一行 import 只是智能体观察到的现象，还算不上领域、能力或依赖。

## 从应用开始

桌面应用提供三种开始方式。

**根据代码构建本体。** 开始卡片上的这个按钮会请你选择代码文件夹。Atlas 会显示将要在该代码文件夹里创建的 `atlas` 文件夹路径（已有则复用），然后等你按下 **创建**。随后它会和你的编码智能体开启一段对话，由智能体读取代码，一次写出第一张地图。每次写入都会征求你的批准。即使开启了 **自动批准**，智能体在绑定代码文件夹之前和完成地图之前仍会询问你。

**开始使用。** 当你打开一个还没有地图的文件夹时，地图上会出现一张卡片，带你完成几个步骤。在代码文件夹中，第一步是 **让智能体根据代码起草地图**。如果应用中已有可用的编码智能体，**交给智能体** 会把这条请求放进地图旁的智能体对话中，由你自己按下 **发送**。否则，**复制提示词** 会复制同样的请求，供你在终端里运行的智能体使用。后面的步骤会连接智能体，然后创建起步文档，或者让你手动开始。

**用本地模型从代码构建。** 在 macOS 应用中，地图旁的智能体面板里有 **从代码创建**。它需要在 **智能体**、**模型** 中设置一个本地模型，例如 Ollama、LM Studio 或 llama.cpp。选择一个代码文件夹后，预览会列出代码文件夹、审查后的改动将保存到哪里、所用的模型、模型地址，以及有多少文件符合条件。**运行** 只会把代码片段发送到那个本地地址。结果是一份文档改动的提议清单，勾选你想要的再应用即可。

## 向智能体提什么要求

第一张地图要小。挑一个你想弄明白的行为，只就这一个行为提出要求。例如：

```text
为这个仓库构建第一张 Atlas 地图，
只聚焦一个行为：[例如接收订单]。

先调用 connection_info，确认本体文件夹和代码仓库。
读取 list_concepts 的统计和已有的概念，避免添加重复项。
把起步文件当作示例，而不是事实。

阅读入口、它的判断条件和失败路径。写入之前，
先提出一小批提议。对每个概念，给出一句定义、
它包含和不包含什么、实现它的文件，
以及你未能核实的内容。对每条关系，说明它为什么成立。

然后停下来，让我修正或批准这一批。
只写入我批准的内容，最后运行 validate_vault。
```

第一轮有几个概念就够了。需要回答别的问题时再继续添加。

## 保存之前先审查

好的提议能让你针对某一条具体的说法提出异议。逐一检查每个概念和每条关系：

- **名称说明它做什么。** 光有一个文件夹名或库名，同事从中得不到多少信息。
- **正文各部分齐全。** 一句定义、`## Includes`、`## Excludes` 和 `## Uncertainty`。缺少其中任何一项时，`validate_vault` 会发出警告。
- **依据指向一个文件。** 能力或元素带有指向代码的 `path`。路径存在并不能证明解释正确，所以要去读一读。
- **关系成立。** 问问自己：把目标移除之后，这项能力是否仍然能工作。仅凭一条 import 并不能证明存在依赖。

批准你真正读过的那一批，再要求下一批。地图的形态稳定下来之后，智能体可以用 `connect_project_source` 把项目绑定到代码文件夹，并用 `finalize_project_meaning` 记录结果。写入成功仍然不等于含义被接受：提交之前请先阅读 diff。

## 复用 CLAUDE.md 和 AGENTS.md

你的智能体指令文件往往已经描述了这个代码库。请智能体对其中一个文件运行 MCP 工具 `absorb_document`。默认情况下它只返回计划。加上 `confirm: true` 后，它会把策略和规则部分保存为 `document` 概念，把原文件备份为 `.pre-absorb.bak`，并把原文件改写成一个简短的指引，保留它没有吸收的部分。架构部分只作为提议，从不自动写入。

如果文件夹里已经有不在地图上的 Markdown 文档，**开始使用** 卡片会增加一个步骤：**用我的文档生成地图**。
