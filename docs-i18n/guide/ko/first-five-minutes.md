# 시작하기

이 장에서는 아무것도 없는 상태에서 시작해 내 온톨로지 폴더를 지도에 띄우고,
Claude Code나 Codex 같은 코딩 에이전트와 첫 작업을 해 보는 데까지 안내해요.
데스크톱 앱에서 하면 돼요.

## 앱 받기

[ontologyatlas.com](https://ontologyatlas.com/ko/download/)에서 내려받으세요.
macOS 빌드는 Apple Silicon용이고 서명과 공증을 마쳤어요. Windows x64 빌드는
서명되지 않은 베타라서, 실행 전에 SmartScreen이 경고할 수 있어요.

앱은 내 폴더를 그 자리에서 읽고, 다음에 열 때는 접근 권한을 다시 묻지 않고 같은
폴더를 다시 열어요. Git 기록, 지도 옆 에이전트 대화, 시스템 자격 증명 저장소에
보관하는 모델 API 키, 클릭 한 번으로 코딩 에이전트에 MCP 서버를 등록하는 기능도
앱에 있어요. 웹 페이지는 내 폴더를 열지 않아요. ontologyatlas.com은 Atlas를
소개하고 앱을 내려받게 해 줄 뿐이에요.

Linux와 Intel Mac용 앱은 없어요. 그럴 때는 아래 샘플 지도를 보거나, 소스
체크아웃에서 MCP 서버를 실행하세요.
[소스 체크아웃에서 연결하기](/guide/connect-agent#connect-from-a-source-checkout)를
참고하세요.

## 샘플 지도 보기

설치하기 전에 [샘플 지도](https://ontologyatlas.com/ko/sample/)에서 Atlas가 어떤
지도를 그리는지 볼 수 있어요. 상품, 주문, 회원, 배송으로 이뤄진 온라인 쇼핑몰이고,
누구나 아는 이름이에요. 읽기 전용이라 폴더를 열지 않아요.

개념을 클릭하면 그 개념이 의존하는 개념과 그 개념을 쓰는 개념으로 가는 선에 불이
들어오고, 패널에 그 이름들이 나와요. 나머지는
[지도 읽는 법](/guide/reading-the-map)에서 설명해요. 앱에서는 내 폴더의 마크다운
파일로 내 코드를 이렇게 그려 줘요.

## 온톨로지 폴더 열기 또는 만들기

열린 폴더가 없으면 앱은 시작하는 방법 네 가지를 보여 줘요.

- **코드 프로젝트에서 시작**: 코드 폴더를 골라요. Atlas가 **이 코드 폴더 안에
  온톨로지 폴더를 만들까요?**라고 물으며 경로를 보여 줘요. **만들기**를 누르면
  코드 폴더 안에 `atlas` 폴더가 생기고, 코드는 그대로 둬요. 앱에 코딩 에이전트가
  준비돼 있으면 이어서 에이전트가 코드를 읽고 첫 지도를 만들어요.
- **홈 폴더에 만들기**: 폴더를 고르는 창 없이 홈 폴더의 `Ontology Atlas` 아래에
  새 폴더를 만들어요.
- **폴더 열기**: 이미 있는 마크다운 폴더를 골라요.
- **빈 폴더에서 시작**: 빈 폴더를 고르면 Atlas가 시작용 마크다운 파일과 에이전트
  설정을 넣어 줘요.

두 "만들기" 방법은 먼저 **이 폴더에 무엇을 담을까요?**라고 물어요. **문서
위키**, **코드로 만든 지도**, **둘 다** 중에서 고르면 돼요. 고르지 않은 쪽은
나중에 설정에서 추가할 수 있어요.

### Atlas가 폴더로 하는 일

마크다운 폴더라면 무엇이든 열 수 있어요. frontmatter에 `kind:` 줄이 있는 파일은
지도 위의 개념이 되고, 나머지 마크다운 파일은 평범한 문서로 남아요. 폴더를
연다고 파일이 옮겨지거나 이름이 바뀌지는 않아요. 폴더 구성은
[온톨로지 폴더](/guide/vault-structure)에서 설명해요.

## 코딩 에이전트와 첫 작업 하기

지도는 코딩 에이전트가 작업 전에 읽을 때 가장 쓸모 있어요. 앱에서는 이렇게
해요.

1. **에이전트**를 열고 **MCP** 탭으로 가요.
2. 쓰는 에이전트 줄에서 **연결**을 눌러요. Claude Code라면 Atlas가 폴더에
   `.mcp.json`을, Codex라면 `.codex/config.toml`을 만들어요. Cursor와
   Antigravity도 목록에 있어요.
3. 그 에이전트를 종료했다가 다시 열어요.
4. 다음에 할 작업을 에이전트에게 물어봐요. 예를 들면 이렇게요. "체크아웃을
   바꾸기 전에, 체크아웃이 건드리는 Atlas 개념을 읽고 체크아웃에 무엇이
   의존하는지 알려 줘."

에이전트는 필요할 때 내 컴퓨터에서 Atlas MCP 서버를 띄워요. 서버는 네트워크
포트를 열지 않아요. 에이전트별 설정, 소스 체크아웃에서 연결하는 방법, 문제 해결은
[MCP로 코딩 에이전트 연결하기](/guide/connect-agent)에서 다뤄요.

폴더에 아직 개념이 없다면 에이전트에게 코드를 읽고 초안을 쓰게 하세요.
방법은 [내 코드로 첫 지도 만들기](/guide/from-your-repo)에서 설명해요.
