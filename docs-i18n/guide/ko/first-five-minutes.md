# 시작하기

이 장에서는 아무것도 없는 상태에서 내 온톨로지 폴더를 지도에 띄우고, Claude
Code나 Codex 같은 코딩 에이전트와 첫 작업을 하기까지를 다뤄요. 데스크톱 앱과
브라우저 어느 쪽에서든 시작할 수 있어요.

## 앱과 브라우저 중에 고르기

- **앱**은 모든 기능을 갖춘 제품이에요.
  [ontologyatlas.com](https://ontologyatlas.com/ko/download/)에서 내려받으세요.
  macOS 빌드는 Apple Silicon용이고 서명과 공증을 마쳤어요. Windows x64 빌드는
  서명되지 않은 베타라서, 실행 전에 SmartScreen이 경고할 수 있어요.
- **브라우저 버전**은 설치가 필요 없어요. 바로 샘플 지도를 열고, Chrome이나
  Edge에서는 디스크의 폴더도 열 수 있어요. Firefox처럼 폴더에 접근할 수 없는
  브라우저에서는 샘플과 앱 링크를 보여 줘요.

몇 가지는 앱에서만 돼요. 다시 열 때 폴더 기억하기, Git 기록, 지도 옆 에이전트
대화, 모델 키, 클릭 한 번으로 코딩 에이전트에 MCP 서버 등록하기예요.

## 샘플 지도 보기(브라우저)

폴더 없이 열면 브라우저는 **지금은 샘플** 표시가 붙은 샘플을 보여 줘요. 샘플은
두 가지 중에서 바꿔 볼 수 있어요.

- **온라인 쇼핑몰**: 상품, 주문, 회원, 배송이에요. 누구나 아는 이름으로 지도
  읽는 법을 익힐 때 좋아요.
- **이 앱의 코드**: Ontology Atlas 저장소의 실제 온톨로지예요. 사람과 에이전트가
  함께 만들고 관리해요.

카드에는 샘플의 크기가 개념, 관계, 도메인 수로 나와요. 개념을 클릭하면 그
개념이 의존하는 것과 그 개념을 쓰는 것으로 가는 선에 불이 들어오고, 패널에
이름이 나와요. 나머지는 [지도 읽는 법](/guide/reading-the-map)에서 설명해요.

## 온톨로지 폴더 열기 또는 만들기

### 앱에서

열린 폴더가 없으면 앱은 시작하는 방법 네 가지를 보여 줘요.

- **코드 프로젝트에서 시작**: 코드 폴더를 골라요. Atlas가 **이 코드 폴더 안에
  온톨로지 폴더를 만들까요?**라고 묻고 경로를 보여 줘요. **만들기**를 누르면 그
  안에 `atlas` 폴더를 만들고, 코드는 건드리지 않아요. 앱에 코딩 에이전트가 준비돼
  있으면, 이어서 에이전트가 코드를 읽고 첫 지도를 써요.
- **홈 폴더에 만들기**: 폴더 고르는 창 없이 홈 폴더의 `Ontology Atlas` 아래에 새
  폴더를 만들어요.
- **폴더 열기**: 이미 있는 마크다운 폴더를 골라요.
- **빈 폴더에서 시작**: 빈 폴더를 고르면 Atlas가 시작용 마크다운 파일과 에이전트
  설정을 넣어 줘요.

두 "만들기" 방법은 먼저 **이 폴더에 무엇을 담을까요?**라고 물어요. **문서
위키**, **코드로 만든 지도**, **둘 다** 중에서 고르면 돼요. 고르지 않은 쪽은
나중에 설정에서 추가할 수 있어요.

### 브라우저에서

**폴더 열기**를 누르세요. 짧은 안내가 무슨 일이 일어나는지 설명한 뒤 **기존
폴더 선택**과 **빈 폴더로 새로 시작**을 보여 줘요. 폴더를 고르면 브라우저가
접근을 허용할지 물어요. 이 권한은 페이지가 내 컴퓨터에 있는 폴더를 읽게 해 줄
뿐이고, 아무것도 업로드하지 않아요.

### Atlas가 폴더로 하는 일

마크다운 폴더라면 어떤 것이든 돼요. frontmatter에 `kind:` 줄이 있는 파일은
지도 위의 개념이 되고, 다른 마크다운 파일은 평범한 문서로 남아요. 폴더를 열어도
파일을 옮기거나 이름을 바꾸지 않아요. 폴더 구성은
[온톨로지 폴더](/guide/vault-structure)에서 설명해요.

## 코딩 에이전트와 첫걸음 떼기

지도는 코딩 에이전트가 작업 전에 읽을 때 가장 쓸모 있어요. 앱에서는 이렇게
해요.

1. **에이전트**를 열고 **MCP** 탭으로 가요.
2. 쓰는 에이전트의 **연결**을 눌러요. Claude Code라면 Atlas가 폴더에
   `.mcp.json`을, Codex라면 `.codex/config.toml`을 써요. Cursor와 Antigravity도
   목록에 있어요.
3. 그 에이전트를 종료했다가 다시 열어요.
4. 다음 작업에 대해 에이전트에게 물어보세요. 예를 들면 "체크아웃을 바꾸기 전에,
   체크아웃이 건드리는 Atlas 개념을 읽고 무엇이 체크아웃에 의존하는지 알려 줘."

에이전트는 필요할 때 내 컴퓨터에서 Atlas MCP 서버를 띄워요. 서버는 네트워크
포트를 열지 않아요. 에이전트별 설정, 브라우저에서 연결하는 경우, 문제 해결은
[MCP로 코딩 에이전트 연결하기](/guide/connect-agent)에서 다뤄요.

폴더에 아직 개념이 없다면 에이전트에게 코드를 읽고 초안을 쓰게 하세요.
[내 코드로 첫 지도 만들기](/guide/from-your-repo)에서 방법을 설명해요.
