# はじめに

この章では、何もないところから自分のオントロジーフォルダをマップに表示し、Claude CodeやCodexなどのコーディングエージェントと最初のタスクに取りかかるところまでを案内します。デスクトップアプリで始めます。

## アプリを入手する

[ontologyatlas.com](https://ontologyatlas.com/ja/download/)からダウンロードできます。macOS版はApple Silicon向けで、署名と公証を済ませています。Windows x64版は署名のないベータ版なので、実行前にSmartScreenが警告を出すことがあります。

アプリは、フォルダをその場で読み、次に開くときはアクセスの許可を求め直さずに同じフォルダを開き直します。Gitの履歴、マップの横でのエージェントとのチャット、システムの資格情報ストアに保管するモデルのAPIキー、そしてMCPサーバをコーディングエージェントにワンクリックで登録する機能もアプリにあります。Webページがフォルダを開くことはありません。ontologyatlas.comはAtlasを紹介し、アプリを渡すだけです。

LinuxとIntel Mac向けのアプリはありません。その場合は、下のサンプルのマップを見るか、ソースのチェックアウトからMCPサーバを実行してください。[ソースのチェックアウトから接続する](/guide/connect-agent#connect-from-a-source-checkout)を参照してください。

## サンプルのマップを見る

インストールする前に、[サンプルのマップ](https://ontologyatlas.com/ja/sample/)でAtlasが描くマップを見られます。商品、注文、会員、配送からなるオンラインストアで、誰でも知っている名前です。読み取り専用で、フォルダは開きません。

概念をクリックすると、その概念が依存しているものと、その概念を使っているものへの線が明るくなり、パネルにそれぞれの名前が表示されます。そのほかの見方は[マップの読み方](/guide/reading-the-map)で説明しています。アプリでは、フォルダのMarkdownファイルから、あなた自身のコードをこのように描きます。

## オントロジーフォルダを開く、または作る

フォルダを開いていないとき、アプリには始め方が4つ表示されます。

- **コードプロジェクトから始める**: コードのフォルダを選びます。Atlasは**このコードフォルダ内にオントロジーフォルダを作成しますか？**と尋ね、パスを表示します。**作成**を押すと、そこに`atlas`フォルダを作り、コードには手を触れません。アプリでコーディングエージェントが使える状態なら、続けてエージェントがコードを読み、最初のマップを書きます。
- **ホームフォルダに作成**: ホームフォルダの`Ontology Atlas`の下に新しいフォルダを作ります。フォルダを選ぶ画面は出ません。
- **フォルダを開く**: 既存のMarkdownフォルダを選びます。
- **空のフォルダで始める**: 空のフォルダを選ぶと、AtlasがスターターのMarkdownファイルとエージェントの設定を追加します。

2つの「作成」の選択肢では、最初に**このフォルダに入れるもの**を尋ねます。**文書のWiki**、**コードのマップ**、**両方**のどれかです。もう一方はあとから設定で追加できます。

### Atlasがフォルダで行うこと

どんなMarkdownフォルダでも使えます。フロントマターに`kind:`の行があるファイルはマップ上の概念になり、それ以外のMarkdownファイルは普通の文書のままです。フォルダを開いても、ファイルを移動したり名前を変えたりはしません。構成については[フォルダ構成](/guide/vault-structure)で説明しています。

## コーディングエージェントと最初の一歩を踏み出す

マップがいちばん役立つのは、コーディングエージェントがタスクの前にマップを読むときです。アプリでは次のようにします。

1. **エージェント**を開き、**MCP**タブを開きます。
2. 使うエージェントの**接続**を押します。Claude Codeの場合、Atlasはフォルダに`.mcp.json`を書き込みます。Codexの場合は`.codex/config.toml`を書き込みます。CursorとAntigravityも一覧にあります。
3. そのエージェントを終了して、もう一度開きます。
4. 次のタスクについてエージェントに尋ねます。たとえば「購入確定の処理を変更する前に、それが関わるAtlasの概念を読んで、何がそれに依存しているかを教えて」のようにします。

エージェントは、必要になったときに手元のコンピュータでAtlasのMCPサーバを起動します。サーバはネットワークポートを開きません。エージェントごとの手順、ソースのチェックアウトからの接続、トラブルシューティングは[MCPでコーディングエージェントを接続](/guide/connect-agent)で説明しています。

フォルダにまだ概念がなければ、コードからエージェントに下書きさせましょう。[コードから最初のマップを作る](/guide/from-your-repo)を参照してください。
