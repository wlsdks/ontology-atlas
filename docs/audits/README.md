# audits/ — 잰 것의 기록

**날짜에 묶인 스냅샷**만 여기 산다. 각 파일은 *그때* 무엇을 쟀고 무엇이 나왔는지의
기록이며, **현재 상태를 주장하지 않는다** — 그래서 나중에 사실과 어긋나도 고치지
않는다(고치면 기록이 아니라 위조다).

규범 문서(오늘 지켜야 하는 것)는 `docs/` 루트에 있다. 이 구분이 흐려지면 감사
보고서가 규격처럼 읽히고, 다음 사람이 이미 지나간 상태를 현행으로 오인한다.

- 여기 넣는 것: 감사 · 리뷰 브리프 · 케이스 스터디 · 실측 보고
- 여기 넣지 않는 것: 오늘 유효한 규칙, 계약, 아키텍처 서술

감사에서 나온 **결정**은 여기 남기지 말고 `docs/DECISIONS.md` 원장에 올린다 —
원장은 반대 의견과 반증 조건까지 함께 남기는 자리다.
