Runs the first-time build of a vault from a repository in one terminal command, so a person can start from nothing without opening the app.

## Includes
- The one-shot path from an empty folder to a first set of nodes and containment.
- The explicit stance that inferred imports stay review-only and are never promoted to dependencies automatically.

## Excludes
- Approving the meaning it proposes.
- Replacing the reviewed batch-by-batch path this vault was actually built with.

## Uncertainty
- Identified from the command file and the indexing tool's description of what a bootstrap may and may not write. The command was not run, so how much it writes without confirmation was not observed here.
