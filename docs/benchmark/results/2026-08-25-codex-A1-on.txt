한 줄 설명: 로컬 디스크의 Markdown 폴더를 데이터 소스로 선택·관리하고, Git을 source of truth로 사용하며, 예시 볼트를 제공하는 로컬 우선 데이터 소스 계층입니다.

직접 연결된 capability는 4개입니다.

- `data-source-mode` — 데이터 출처 모드 분기: 폴더 선택 여부에 따라 vault-picked 모드와 static/sample 모드로 앱 동작을 분기합니다.
- `docs-vault-local` — 내 폴더 열기: File System Access API로 로컬 Markdown 폴더를 선택·마운트합니다.
- `project-data-source` — 프로젝트 데이터 읽기: 로컬 볼트 또는 샘플에서 프로젝트 목록·본문을 읽고, 로컬 모드에서 CRUD를 제공합니다.
- `vault-sample-source` — 예시 볼트 출처: 설치 없이 사용할 수 있는 번들 샘플 볼트를 제공합니다.

직접 연결된 element는 8개입니다.

- `atlas-git-panel` — 볼트의 Git 상태·스냅샷을 보여주는 패널
- `docs-vault-entity` — 볼트 데이터 모델 엔티티
- `docs-vault-view` — `/docs` 화면
- `docs-vault-widget` — 볼트 트리/목록 UI 위젯
- `git` — Git 상태·히스토리 화면
- `local-fs-handle` — File System Access API 핸들 엔티티
- `native-vault-filesystem-bridge` — Tauri WebView와 선택된 볼트 사이의 파일시스템 읽기·쓰기 브리지
- `private-vault-sidecar-boundary` — MCP/CLI의 `.ontology-atlas` 내부 영수증·활동 로그를 다루는 파일 경계

참고로 `project-data-source`는 `elements/project`도 연결하지만, 해당 element의 소속 도메인은 `project-portfolio`이므로 `local-vault-management`의 직접 element 목록에는 포함되지 않습니다.
