# 디자인 전면 정비 마스터 플랜 (2026-07-25, 소유자 실보고 22건)

> 소유자가 실사용 스크린샷과 함께 보고한 22건 + "디자인 시스템 구축"이라는
> 메타 과제를 기록한 **단일 진실원 계획 문서**. 프로세스: **fable 기획 →
> opus 검수 → sonnet/opus 코딩**. 항목마다 상태를 갱신한다 (☐ 대기 · ◐ 진행 ·
> ☑ 완료 · ✗ 반려/보류). 세션이 바뀌어도 이 문서만 읽으면 이어서 작업 가능해야 한다.

## 대원칙 — 디자인 시스템이 본체다 (소유자 강조)

> "모든 디자인의 토큰화 — 사이즈·모양 다 코드로 구성되어야 한다."

22건 중 다수(4·6·8·13·16·17)는 개별 수정이 아니라 **시스템 부재의 증상**이다.
따라서 Phase 1 에서 캐노니컬 컴포넌트/토큰을 먼저 세우고, 이후 항목은 그
시스템 위에서 고친다. 산출물은 `docs/DESIGN-SYSTEM.md` 갱신 + `app/globals.css`
토큰 + `src/shared/ui/` 캐노니컬 컴포넌트.

기존 자산 (이미 있음 — 중복 생성 금지):
- 색: `--color-*` 5단계 서피스 + 단일 인디고 사다리 + 신호톤 3종
- 타입 램프: `--text-label(11)…--text-large(32)` + `TYPE_RAMP_STEPS`(cn.ts)
- 컨트롤: 크롬 타일 36px 계약, 최근 공방 하단 바 32px 체계, select 40px
- 다크 캐노니컬 토스트(sonner, #599) · 팝오버/모달 스크림 패턴(공방)

## 전체 22건 기록 (소유자 원문 요지 + 화면 증거)

### A. 디자인 시스템 파운데이션 (Phase 1 — 최우선)

- ☐ **#4 커스텀 셀렉트/드롭다운.** 공방 만들기의 도메인 select 를 열면 macOS
  기본 회색 네이티브 드롭다운(파란 하이라이트)이 떠 다크 앱에서 이질적.
  → 캐노니컬 **다크 listbox 컴포넌트** (`src/shared/ui/select.tsx` 신규):
  panel 서피스·인디고 하이라이트·키보드 내비·a11y(role=listbox). 앱 전역의
  네이티브 select 를 이걸로 교체(공방·개념 추가 팝업·설정 등 전수).
- ☐ **#13 지도 우상단 툴바 박스 크기 불일치.** "+ 개념" 버튼이 옆 버튼들과
  높이/모양 안 맞음. → **툴바 컨트롤 높이 토큰**(`--control-h-md` 등) 정의,
  지도 상단 버튼 전수 정렬. (공방 32px 체계와 통일 검토)
- ☐ **#16 빈 상태(empty state) 패턴.** 인사이트 "가장 많이 기대는 곳" 등
  데이터 없으면 긴 공백만. → **캐노니컬 empty-state 컴포넌트**: 자리표시
  모양(muted 스켈레톤/일러스트 라인아트) + 한 줄 안내 + (가능하면) 다음 행동
  버튼. 앱 전역 빈 상태 전수 적용.
- ☐ **#6 공방 소켓 박스 비율.** 상/좌/우 빈 소켓 박스의 글자가 커 보이고
  비율 어색. → 소켓 타이포 스케일 재조정(질문 문구 text-callout→caption 검토),
  내부 패딩 규칙 토큰화, 콘텐츠에 따라 유연한 박스 사이즈(고정 폭 대신
  min/max 규칙). 디자인 가디언 광학 검수 필수.
- ☐ **#17 설정 > AI 에이전트 연결 패널 재설계.** 모노스페이스 CONFIG_STATE/
  MCP_VERIFY 나열이 "AI 가 급조한" 느낌 — 앱의 다른 표면과 다름. → 캐노니컬
  카드/리스트 문법으로 재설계(#12 원클릭과 함께 진행).
- ☐ **디자인 시스템 문서화.** 위 컴포넌트/토큰을 `docs/DESIGN-SYSTEM.md` 에
  "컨트롤 인벤토리" 절로 명문화: select·dialog(사이즈 스케일)·empty-state·
  toolbar 컨트롤 높이·모션 문법(아래 C).

### B. 지도(Topology) 정합 (Phase 2)

- ☐ **#5 선택 노드 vs 연결 노드 구분.** 노드 선택 시 엣지는 보이는데 상대
  노드가 강조 안 돼 안 보임. → 선택 노드=표준 인디고 링, **연결 이웃=pale
  인디고(기존 `--topology-v2-edge-selected` 계열) 얇은 링**. 헌장의 "선택 색
  사다리 = 인디고 1계열 안에서 값으로만 구분" 준수(파란색 새 hue 금지 —
  소유자 의도는 '구분'이므로 인디고 사다리로 충족).
- ☐ **#8 개념 추가 팝업.** 너무 작음 → 화면 중앙 더 크게(dialog 사이즈
  스케일 md→lg). "도메인 slug(선택)" 은 비개발자 불가해 → 평문화("어느
  묶음(도메인)에 넣을까요? (선택)") + 도메인이 뭔지 툴팁/한줄 설명 +

  후 제거(또는 유지 근거 제시). 제거 시 e2e/i18n/문서 스윕 포함.

## 프로세스

- **fable**: 판정/정보구조/모션 카탈로그 기획. **opus**: 구현 검수 + 가디언
  디자인 검수. **sonnet**: 명세 명확한 코딩 슬라이스. 구현은 워크트리, 머지
  전 브라우저 검증(스크린샷/동영상), 헌장 준수 grep.
- 항목 완료 시 이 문서의 체크박스 갱신 + CHANGELOG 반영.
