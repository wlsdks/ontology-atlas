# 디자인 전면 정비 마스터 플랜 (2026-07-25, 소유자 실보고 22건)

> 소유자가 실사용 스크린샷과 함께 보고한 22건 + "디자인 시스템 구축"이라는
> 메타 과제를 기록한 **단일 진실원 계획 문서**. 프로세스: **fable 기획 →
> opus 검수 → sonnet/opus 코딩**. 항목마다 상태를 갱신한다 (☐ 대기 · ◐ 진행 ·
> ☑ 완료 · ✗ 반려/보류). 세션이 바뀌어도 이 문서만 읽으면 이어서 작업 가능해야 한다.

## 대원칙 — 디자인 시스템이 본체다 (소유자 강조)

> "모든 디자인의 토큰화 — 사이즈·모양 다 코드로 구성되어야 한다."

22건 중 다수(4·6·8·13·16·17)는 개별 수정이 아니라 **시스템 부재의 증상**이다.
따라서 Phase 1 에서 캐노니컬 컴포넌트/토큰을 먼저 세우고, 이후 항목은 그
시스템 위에서 고친다. 산출물은 `docs/DESIGN-SYSTEM.md` 갱신 + `app/globals.css`
토큰 + `src/shared/ui/` 캐노니컬 컴포넌트.

기존 자산 (이미 있음 — 중복 생성 금지):
- 색: `--color-*` 5단계 서피스 + 단일 인디고 사다리 + 신호톤 3종
- 타입 램프: `--text-label(11)…--text-large(32)` + `TYPE_RAMP_STEPS`(cn.ts)
- 컨트롤: 크롬 타일 36px 계약, 최근 공방 하단 바 32px 체계, select 40px
- 다크 캐노니컬 토스트(sonner, #599) · 팝오버/모달 스크림 패턴(공방)
