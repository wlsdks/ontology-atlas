# Smart entry

### `/` — Smart entry

- **A plain browser** → the **gateway face** — headline, download, and "See a sample map" (`/sample`) — the same view `/download` renders. It never opens a folder: no page of the website reads or remembers one (2026-11-27; before that, 2026-07-30 reversed opening the map directly from the root). Under the buttons one sentence names the computers that have an app. The installed app never shows it: the boot script marks `<html data-shell="desktop">` and `nav-destination.ts` sends the app to the map or first run.
- **`/sample`**: the Storefront sample (125 concept documents) drawn by the app's map renderer, read-only, under a line saying what it is. Pan, zoom and press a concept for its name, kind, first paragraph and relations in the compact panel; there is no rail, open-folder control, edit or agent panel. If the data does not arrive it says so and offers "Try again". "Get the app" opens `/download`.
- **Every app address in a plain browser** → the **app-only page**: "Ontology Atlas runs in the installed app", with "Get the app", "See a sample map" and the other-computers sentence, from the first paint and with scripts off, `noindex`. The address bar keeps what was typed. Each app route's HTML carries both the workbench and this page; CSS keyed on `data-shell="desktop"` paints exactly one.
- **Canonical home**: `/{locale}/download/` is the indexed face (2026-10-03). `/` and `/{locale}/` canonicalize to it, the sitemap lists it at priority 1 and omits `/{locale}/`, and `pnpm seo:check` holds that after every Pages build.
- **Search reach (2026-11-19)**: every meta description fits 25-160 characters (`fitMetaDescription` in `page-metadata.ts`, after Bing flagged 20 of 152 pages). Each locale's metadata carries `keywords` in the words its searchers type and `brandReading`, the brand as that language reads it aloud in its own script, which the download page's `SoftwareApplication` lists as an `alternateName`; the Chinese title, keywords and descriptions also name the Chinese term for a knowledge graph, a common search for this subject, while the tagline keeps leading with shared meaning. After each Pages deploy, the pages whose visible text changed against the live site go to IndexNow (`scripts/web/indexnow.mjs`, key served at `/<key>.txt`), so Bing, which also feeds ChatGPT search, and Naver, Yandex and Seznam recrawl them within minutes; Google reads the sitemap.
- **Index signals (2026-11-20)**: only pages with their own static words are indexable. The app routes (agents, architecture, automations, changes, git, library, planning, projects, and the legacy `/docs` and `/mcp`) answer a browser with the app-only page, which is `noindex, follow` with no canonical or hreflang (`noindex` in `buildPageMetadata`); the sitemap lists `/sample` and neither `/topology` nor a `/project/` address; `pnpm seo:check` fails an indexable page that is neither in the sitemap nor consolidated into a sitemap URL. The changelog is one page of record, `/en/changelog/`: its entries are English, so the other locales canonicalize there (`CHANGELOG_CONTENT_LOCALES`). The root layout declares one `Organization` (`#org`, logo, `sameAs`) and `WebSite` (`#website`); other JSON-LD references `#org` as author and publisher. Indexable pages name the other locales in `og:locale:alternate`.
- **Desktop app, no restored vault** → `FirstRunPage` (start from a code project / just start / open / create), with no workbench rail until a folder's first part has arrived
- **Recent desktop vaults** → the picker stores recently opened Tauri vault paths, can reopen them without another Finder selection, and can remove stale paths from the list
- **Vault loaded** → `HomePage` — the topology hub for that vault (map + INDEX concept panel + node datasheet), the same component `/topology` renders (B3 decision ["Don't keep a separate hub; the map takes its place"] — the old tree/ego hub, `OntologyViewPage`, is retired; `/ontology` now redirects here with INDEX expanded). Restoring a previously-opened vault handle from IndexedDB goes straight here — no starter surfaces, no re-clicking through first-run every visit
- **Switch vault mid-session**: the topology settings gear (⚙, top-right utility rail) has a "switch vault" row → `/docs/?intent=local`, alongside the `/docs` vault pill's own "swap" control
