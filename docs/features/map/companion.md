# Companion retirement

The companion game and all related journal, reflection and learning screens
were retired at the owner's request on October 2, 2026. Folder entry, document
inspection, agent approvals and verified work status remain available.

Existing device-local personal/game saves are left untouched. Atlas no longer
reads or writes them and provides no replacement viewer or export flow.
Historical decisions remain in the immutable decision ledger.
