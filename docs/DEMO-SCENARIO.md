# 시연 영상 촬영 시나리오 — `atlas-tour` (2026-08-03)

> 한 클립 · 45초 · 무컷 · 무음 · 루프 없음 · **한국어/영어 따로 촬영**.
> 재생 계약의 구현은 `src/views/download/ui/DemoStage.tsx`, 자산 등록부는
> `src/views/download/model/demo-clips.ts`.

## 0. 무엇이 바뀌었나

종전은 **2클립 2탭**(`one-folder` 24초 + `one-button` 14초)에 언어별 `.vtt`
자막이었다. 셋을 바꾼다:

| | 종전 | 지금 | 왜 |
|---|---|---|---|
| 클립 수 | 2 (탭) | **1** | 첫인상 자리에서 「무엇을 볼지 고르기」는 비용이지 값이 아니다. 대부분은 첫 탭만 보고 떠나므로 두 번째는 만들었지만 아무도 안 보는 것이 된다 |
| 자막 | `.vtt` 를 DOM 이 그림 | **없음** | 언어별로 따로 찍으므로 화면 안의 글자가 이미 그 언어다. 자막이 더할 정보가 없다 |
| 로케일 | 한 마스터 + 자막 2벌 | **영상 2벌** | 화면 안 UI 문구가 언어를 탄다 |

## 1. 이 영상이 벌어야 하는 한 문장

> **내 폴더가 지도가 되고, 내 에이전트가 그 지도를 같이 쓴다.**

45초가 끝났을 때 관객이 갖는 문장이 이것이 아니면 시나리오가 틀린 것이다.
기능 나열이 아니라 **한 사람의 5분**을 압축한 것이어야 한다.

## 2. 촬영 규격

| 항목 | 값 |
|---|---|
| 해상도 | 1512 × 918 (14" 논리 해상도 · 앱 창을 화면에 꽉) |
| 길이 | 45초 ±3초 — `DEMO_CLIPS[0].seconds` 와 맞춘다 |
| 컷 | **0** — 한 테이크. 실수하면 처음부터 |
| 소리 | 없음 (BGM 포함 0) |
| 커서 | 보인다. 클릭 하이라이트는 쓰지 않는다 |
| 속도 | 등속. 배속·점프 금지 |
| 전달물 | `atlas-tour.{ko,en}.webm` + `.mp4` + `atlas-tour.{ko,en}-poster.png` |

**볼트는 실물이어야 한다.** 데모용으로 만든 3노드짜리 폴더는 첫 화면에서
「이거 장난감이네」로 읽힌다. `docs/ontology`(현재 71노드 · 91관계)를 쓴다.

**언어 전환**: 설정 › 화면 › 언어에서 EN/KO 를 바꾼 뒤 **같은 동선을 다시**
찍는다. 두 영상의 길이 차가 5초를 넘으면 한쪽이 다른 동선을 탄 것이다.

## 3. 비트 — 45초

각 비트의 «남는 그림»이 그 구간의 목적이다. 그림이 안 남으면 그 비트는 없어도
된다.

| 초 | 무엇을 한다 | 남는 그림 |
|---|---|---|
| 0–5 | **폴더를 고른다.** 첫 화면에서 「기존 폴더 선택」 → OS 픽커에서 실제 폴더를 고른다 | 내 디스크의 평범한 폴더 |
| 5–12 | **지도가 선다.** 노드가 자리를 잡고 라벨이 뜬다. 손대지 않고 기다린다 | 폴더가 그림이 되는 순간 |
| 12–20 | **노드 하나를 누른다.** ego 포커스 + 팝오버가 뜨고, 성질과 이웃이 보인다 | 「이게 무엇이고 무엇과 이어졌나」 |
| 20–28 | **INDEX 에서 검색한다.** 개념 이름을 치고 결과를 눌러 지도가 그쪽으로 간다 | 71개 안에서 하나를 찾는 속도 |
| 28–36 | **에이전트를 연결한다.** 「연결 안내 열기」 → Claude Code 버튼 한 번 → 「연결됐어요」 | 설정 파일을 손대지 않는다 |
| 36–45 | **기록으로 간다.** 걸음 하나를 눌러 바뀐 개념과 그 걸음이 쓴 줄을 보여준다 | 사람과 에이전트가 같은 것을 본다 |

### 비트 사이 규칙

- **각 비트의 마지막 1초는 정지**다. 손을 떼고 화면이 서 있게 둔다 — 관객의
  눈이 도착하기 전에 다음 동작이 시작되면 아무것도 안 남는다.
- **오타·되돌리기·망설임은 다시 찍는다.** 무컷이라 그 시간이 그대로 남는다.
- **안내 오버레이는 미리 끈다** — 설정 › 알림 › 「화면 안내 자동 표시: 끔」
  또는 URL 에 `?guides=off`. 투어 카드가 뜨면 화면 절반이 덮인다.

## 4. 찍기 전 체크리스트

## 5. 찍은 뒤 — 켜는 절차

```bash
# 1) 자산을 넣는다 (webm + mp4 + poster, 로케일별)
public/demo/atlas-tour.ko.webm
public/demo/atlas-tour.ko.mp4
public/demo/atlas-tour.ko-poster.png
public/demo/atlas-tour.en.webm
public/demo/atlas-tour.en.mp4
public/demo/atlas-tour.en-poster.png

# 2) 길이를 실측해 DEMO_CLIPS[0].seconds 와 맞춘다
ffprobe -v error -show_entries format=duration -of csv=p=0 public/demo/atlas-tour.ko.mp4

# 3) 등록부를 켠다 — 이 줄을 고치기 전에는 절이 안 뜬다
#    src/views/download/model/demo-clips.ts
#    export const AVAILABLE_DEMO_CLIP_IDS = ['atlas-tour'];
```

**자산과 선언이 둘 다 있어야 켜진다.** 파일 존재만으로 켜면 반쯤 올라간 자산이
첫인상 자리에 그대로 나간다.

## 7. 지금 붙어 있는 것 — 2026-08-19 촬영본

`atlas-tour.{ko,en}.*` 는 **실측 88.83초 무컷 한 테이크**다(등록부 `seconds: 89`).
설치본에서 이 저장소의 볼트 `docs/ontology`(82노드)를 열어 찍었다.

**위 3절의 45초 비트표는 2026-08-03 판이고, 이 촬영본은 그것을 따르지 않았다.**
그때는 3D 배치가 하나도 없었다. 소유자가 이름을 대어 요구한 것만 세도 2D 클릭 ·
3D 클릭 · 돔 · 구름 · 에이전트 왕복 다섯이고, 그중 넷은 «형성되는 것을 보는» 것이
요점이라 정지 화면으로 줄일 수 없다. 길이를 지키려면 요구받은 내용을 빼야 했다 —
그건 만드는 쪽이 혼자 할 결정이 아니다. 근거와 기록된 반대(그리고 그 반대가
옳았다면 무엇이 관측될지)는 `docs/DECISIONS.md` (87).

| 초(대략) | 무엇이 보이나 |
|---|---|
| 0–8 | 첫 실행 → 내 폴더 열기 → OS 픽커에서 실제 폴더 |
| 8–14 | 82노드 지도가 선다 |
| 14–20 | 2D 노드 클릭 — ego 포커스 + 타입 있는 사실 패널 |
| 20–30 | 3D 고르개 → **돔** 조립 + 진입 스윕 |
| 30–34 | 돔 **안**을 끌어 손으로 회전 |
| 34–42 | 왼쪽 목록에서 고르면 돔이 그쪽으로 다시 잡힌다 (3D 노드 선택) |
| 42–56 | **구름** 형성·퍼짐 → 회전 |
| 56–62 | **평면** 복귀 |
| 62–89 | **Codex 를 ACP 로**(읽기만) 붙여 이 폴더에 물어보고 답을 받는다 |

**두 로케일이 아직 같은 마스터를 가리킨다** — 화면 글자는 한국어다. 영어 촬영본이
미뤄진 이유는 좌표 동선이 **문구 폭에 매여** 있어서다(칩 라벨이 「자동 정렬」 →
`Auto layout` 으로 바뀌면 이 테이크의 좌표가 통째로 어긋난다). 화면이 그 사실을
`demoProvisionalNote` 로 계속 말한다.

### 다시 찍을 때 — 이번에 배운 것 넷

1. **앱을 재배포하면 볼트 선택과 에이전트 설정이 초기화된다.** 그래서 첫 실행
   화면부터 찍을 수 있고, 대신 실행기·모델 선택도 테이크 안에서 해야 한다.
2. **OS 폴더 픽커는 마지막 위치를 기억한다.** 한 번 손으로 `docs/ontology` 까지
   들어가 두면 촬영 때는 「기존 폴더 선택 → Open」 두 번이면 된다.
3. **칩 좌표는 패널 개폐에 따라 흔들린다.** 오른쪽 패널이 열리면 칩이 아이콘만
   남아 행이 좁아진다. 두 배치의 **교집합**을 눌러야 어느 쪽이어도 맞는다
   (이번 3D 칩은 x=858).
4. **지도 위 노드를 좌표로 누르는 것은 마지막 수단이다.** 회전 뒤 위치는 예측이
   안 된다. **왼쪽 목록(INDEX)의 행**은 자리가 고정이라, 3D 에서 노드를 고르는
   장면은 목록에서 고르는 편이 확실하고 «목록과 지도가 같은 것을 본다»까지 보여
   준다.

**교체 절차**: 위 여섯 파일을 새 촬영본으로 덮고 `DEMO_CLIPS[0].seconds` 를
ffprobe 실측값으로 고친다. 구 자산(`one-folder.*` · `one-button.*`)은
2026-08-19 에 지웠다.
