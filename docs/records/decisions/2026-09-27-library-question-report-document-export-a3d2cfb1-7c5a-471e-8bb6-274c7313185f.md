## 2026-09-27 — A question can become an unreviewed report and local document

**Why**: The owner wants a Wiki question to produce one readable synthesis, not only a list of matches or an answer stranded in the ACP dock. A report should travel as a document with its limits intact.
**Prior**: The 2026-09-27 question desk and optional Jev decision stands. Existing retained answers file only after a person presses Save and the Wiki validator accepts them. Existing Docs printing and analysis Markdown download provide local export mechanisms.
**Decision**: After local evidence search, an explicit ACP action asks for answer, cited evidence, disagreements and unknowns. Its actual response appears above the leads as an unreviewed agent draft; source citations open only inventoried originals. Filing uses the existing Wiki answer validator and concurrency path. Export uses one report model and one editorial template: local Markdown download and a print-only light document opened through the app's Print/Save as PDF dialog. Both carry the question, draft status, answer, citations, search coverage, omissions and generated time. Export does not include the Jev key or treat Jev advice as accepted meaning. No background generation, backend, or automatic vault write is added.
**Dissent**: A polished report can imply verified truth; a print dialog may render differently in WebKit, and local citation addresses may not open for a recipient. Label draft and source limits on screen and in files; prove both exports in the installed app.
**Falsifier**: The report hides unsupported claims, a source link resolves outside the opened folder, exported MD and PDF diverge, stale evidence exports as current, printing includes app chrome, or a user cannot save a real PDF or Markdown file from the installed app.
