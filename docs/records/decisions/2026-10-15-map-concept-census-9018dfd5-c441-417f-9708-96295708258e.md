## 2026-10-15 — "Concepts" on the map's surfaces counts the four kinds the map draws

**Why**: One vault of 99 nodes read as six numbers: INDEX 100 documents, a tree root of 92, the hub 97, the readout 97, the screen-reader census 98 and full detail 99. A person comparing the INDEX with full detail could not tell which was true.
**Prior**: #1704 ("one word, one number", 2026-09-20) set the rule that every count using the word "concept" goes through `canonical-census.ts`, its membership a shared predicate, not a second list. Its predicate, `isCanonicalConcept`, counted everything but the vault readme, documents included. This narrows the census, not the rule; `isCanonicalConcept` keeps its membership for Git's changed-concept list, so a document file still reads as a concept there.
**Decision**: `isMapConcept` (project, domain, capability, element) is the census predicate, and `computeCanonicalCensus` counts those nodes and only the relations between them (97 for the dogfood vault). The map adapter, the INDEX census and project row, the readout, full detail's census, reach denominator and domain partners, and the insights brief headline go through it; the folder's Markdown count stays labelled as documents. The hub and the dial's screen-reader probe count with `dialConceptTotal`, which reads the dial model built from the same adapter output; it agrees with the census except that the containment tree holds one project, and keeps its helper because the dial has two consumers and another owner.
**Dissent**: The specification lists `document` as an authorable concept kind, so 98 is also defensible; answered by scope: these surfaces describe the map, and a document is reached as evidence of a drawn concept, not drawn itself.
**Falsifier**: Two surfaces on the map route state different concept counts for the same vault; in particular a vault with two project nodes shows a hub one lower than the INDEX, which would make the dial's exception visible and require the hub to read the census.
**Owner**: Project owner, via the M5 map-detail brief of 2026-10-15.
