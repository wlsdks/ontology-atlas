## 2026-10-23 — Keep Flat branch grammar across density and scope

**Why**: The default nine-domain sample and a focused domain returned to old orbital forms. A forced-open scope root still offered a no-op collapse control, and capability preview text was not an action.
**Prior**: Decision d170c030-35e9-4a0d-82b4-fcc00683c76b retained packed rings above six domains or 48 preview rows. Present source and the nine-domain rendered sample reproduce that split; the assumption that density needs another visual grammar no longer holds.
**Decision**: Supersede those Flat fallback thresholds with bounded previews and stable column groups. Flat focused domains reuse branch marks with actual kinds; smaller scopes use a containment tree. Reveal/collapse changes real members with interruptible fading. A labelled Full map return restores the selected root. Keep 3D and the existing neutral ink, ports and light masking.
**Dissent**: Branches may need more space than rings on very dense graphs, and naming cannot expose every concept simultaneously. Progressive disclosure and selection priority must preserve access without promising full overview labels.
**Falsifier**: Reconsider the layout if default or dense fixtures hide a selected concept, overlap visible names, lose a return path, or exceed the recorded interaction budget after fitting and disclosure.
