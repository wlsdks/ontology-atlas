## 2026-10-02 — Technical terms stay as written; a tooltip carries the explanation

**Why**: The owner's instruction of 2026-10-02: Korean developers say MCP, ACP, API key and CLI in English, so an invented Korean name with the acronym in parentheses makes them learn a second name. A newcomer still needs the meaning, which an info icon can give without changing the label.
**Prior**: The parenthesis rule in `docs/GLOSSARY.md` and the bare-acronym gate in `plain-language-catalog.contract.test.ts` demanded a Korean gloss beside every acronym in each namespace.
**Decision**: Labels use the term as written (MCP, API key, CLI); English drops "agent connection (MCP)" for "MCP". `TermHint` shows the expansion and one sentence in the current locale on hover, focus or tap, from `src/shared/config/term-glossary.ts` and `messages/{en,ko}/termHints.json`, placed at the first prominent occurrence on a screen. The gate now requires a glossary entry and a drawn `TermHint` per term. The `frontmatter` parenthesis rule stays as written.
**Dissent**: A reader who never opens the icon sees three capital letters with no gloss in the sentence itself.
**Falsifier**: Walkthroughs with newcomers show they do not find or open the hint and misread MCP, ACP or CLI as a result.
