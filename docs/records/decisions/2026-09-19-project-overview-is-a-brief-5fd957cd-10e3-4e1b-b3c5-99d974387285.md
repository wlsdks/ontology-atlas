## 2026-09-19 — The project overview is a brief the agent lays out and a person reviews

**Why**: The owner, on the sample's overview tab: one run of prose is "really unpleasant to look at", and this is the place the agent should analyse and lay out. A body is Markdown, so its shape is already the file's: `##` opens a section, an ordered list is a sequence, a bullet list is a set.
**Prior**: 2026-09-15 (Projects stays a compact index) and 2026-09-12 (the reading column) stand; the brief sits in that column.
**Decision**: The overview draws the body as a brief: each `##` section a numbered block, an ordered list a strip of steps, a bullet list rows, wikilinks doors to the cited document; a body without `##` stays prose. Below it the page hands an agent exact instructions (read the project through MCP, write four sections, change only the body with `patch_concept` under `expected_mtime`); the person reviews in the Library. The page writes nothing and starts no turn. The sample carries the four sections.
**Dissent**: none. Nearest objection: a template invites filling four headings the map does not support; the instructions forbid that and the Library review is the check.
**Falsifier**: a brief whose "where to look next" names a document the map lacks, or an owner who reads the step strip as an order the map never stated. Then sections return to prose and the ask is withdrawn.
**Owner**: the owner (2026-09-19 instruction); applied by Claude.
