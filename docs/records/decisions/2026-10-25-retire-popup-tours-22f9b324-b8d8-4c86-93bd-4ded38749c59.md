## 2026-10-25 — Retire step-by-step popup tours

**Why**: in a fresh source build used in macOS full screen, the map tour described dot size and INDEX while the visible map used named cards and Concepts. Modal steps obscured the workbench and repeated help already present beside concepts and relations. The owner approved removing popup tours and replay entries while retaining contextual help.
**Prior**: partially overturns the tour action and developer-tour branch of 2026-10-02 first-run-card-one-next-step (1a3978e8-87cd-4423-9586-49c0f06e8728). Its folder-first action, sample switch, glossary and folded alternative starts remain.
**Decision**: remove map and destination popup tours, automatic tour launch, replay controls and tour-only canvas instrumentation. Keep folder opening guidance, contextual explanations, keyboard help, glossary and the Guide documentation. Preserve local user data and existing onboarding preferences.
**Dissent**: newcomers may miss a task that a tour would demonstrate. Prefer directly labelled actions and help beside the task; reopen only if an observed task cannot be completed using those entries.
**Falsifier**: a first-use walkthrough cannot open a folder, find a concept, read its original meaning or discover relationship and keyboard help without intervention.
**Owner**: owner-approved in the current usability audit.
