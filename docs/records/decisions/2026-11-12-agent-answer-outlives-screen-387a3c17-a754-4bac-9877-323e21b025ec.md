## 2026-11-12 — An answer being written outlives the screen it was asked on

**Why**: owner, 2026-11-12 (in Korean), after the docks learned to reopen the latest conversation: yes, change it so the agent keeps working when the person moves to another screen mid-answer; use must be seamless. A dock is part of its page, so leaving the page unmounted the chat panel, and the session hook's cleanup stopped the adapter: the answer in flight died and only earlier turns came back.
**Prior**: closes the dissent of 2026-11-12 "Every agent dock reopens the folder's latest conversation" (3d193088). Keeps 2026-09-08 (resume the latest; *New conversation* turns it off) and 2026-09-28 (a put-away conversation stops its process after ten idle minutes), which now also covers a kept panel once its answer ends.
**Decision**: the chat panel renders from one keeper in the locale layout, through a portal into a node the dock seats. Leaving a screen parks the node hidden and inert. A panel at rest is dropped as before. A panel that is answering, or waiting on a permission, is kept, put away, with the callbacks that could move a screen the person is not on removed; it stays, transcript intact, until the person returns to that dock, where the same panel is seated again with the tool it was asked with. Opening the agent on another screen for the same folder ends a kept panel first, so two adapters never hold one conversation. Each kept panel has its own error boundary, and the keeper clears its store when it unmounts (a language switch), so no panel is revived with a fresh session. Kept on the map, the project page, Analysis and Structure. Not kept: the Library, whose page compares the folder before and after a turn and writes `wiki/log.md` from it, so a turn finishing without the page would log a wrong line; and a gray-area investigation on the map, whose basis lives in the page. Both end with the screen as before. Weighed against lifting the session hook into a store, which rewrites 1,361 lines of refs for the same result.
**Dissent**: while away nothing shows that the agent is still working or waiting on a permission; a write receipt for a turn that ends while away reaches no review surface; opening the agent elsewhere still ends the kept answer; a kept panel waiting on a permission for another folder has no time ceiling and holds its adapter until the app quits or the person returns; the Library and investigations still lose the answer in flight. A rail mark for "working" and "waiting on you" would close the first and bound the fourth.
**Falsifier**: a person returns to an answer that stopped although they opened no other agent; a kept panel moves the map or the route while the person is elsewhere; or two adapter processes run for one folder.
