## 2026-10-03 — First-construction discovery is opt-in and does not earn a quality claim

**Why**: One unfamiliar-source ACP pair showed 24.0% smaller input definitions, but source-hidden coverage fell from 3/6 to 2/6 and citation/semantic defects remained.
**Prior**: Keep the runtime registry's mode-aware inventory decision (2026-08-14) and categorical construction qualification (2026-08-09) standing; this adds discovery selection only.
**Decision**: Offer explicit full/construction discovery with 20 existing first-build tools, preserving default full, schemas, direct-call dispatch, read-only and consent guards. Publish cost, quality and failed attempts separately; no speed or quality promotion.
**Dissent**: Fewer tools may not reduce real model work, and this pair lost a core priority rule; reviewer retained mandatory indexing and query tools and required matched evidence.
**Falsifier**: A first build needs an omitted schema, a permission guard changes, or repeated matched trials cannot preserve handoff quality; reconsider the profile rather than change the default.
**Owner**: Product owner; one shared-context reviewer did not implement the change.
