**Observed**: A prior lesson8c613557-44d0-48d2-9a38-aed7a2b1211f recorded treating an exec yield as completion before a dependent build. This turn repeated that pattern: git push still ran its unit pre-push lane when gh pr create started. GraphQL rejected the missing remote head. The same push handle later completed successfully; the unit lane took40seconds.
**Cost**: One rejected draft-creation command; no CI run or source loss.
**Suspected cause**: A yielded process handle was still live, but a downstream action requiring its remote result was started.
**Proposed change**: none. Await terminal exit and verify the remote head before creating the pull request. Keep dependency ordering sequential even when read-only work can continue alongside a live process.
