**Observed**: #2088's first version kept only the open folder's change baseline in localStorage and deleted every other folder's on each save, following the brief's "keep only the current vault's entry". The independent review found it undid #828 (13a460caf, "B's first mark overwrote A's baseline"), whose test "Returning to A restores A's own baseline" I had rewritten to assert the opposite. `pnpm decisions:find` and `git log -S "change-baseline:v1:"` were not run before changing the persisted-per-vault behaviour.
**Cost**: one review round and a rework of the store, its tests and the scope-registry notes (about 45 minutes).
**Suspected cause**: a brief's instruction was treated as the decision, and an existing test that contradicted it was edited instead of read as a recorded fix.
**Proposed change**: skill, one line where storage or persisted-state work is routed: before rewriting a test that encodes cross-scope behaviour, find its origin with `git log -S` on the key and `pnpm decisions:find`, and stop to ask when the brief would reverse it.
