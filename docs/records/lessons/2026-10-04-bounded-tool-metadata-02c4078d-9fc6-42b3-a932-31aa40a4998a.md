**Observed**: Printing full `ALL_TOOLS` metadata for four ontology discovery tools returned 45,080 tokens and was truncated. Each description contains the full shared usage guide before its declaration. A later call printed only the suffix beginning at `exec tool declaration:` for three tools and returned usable schemas without the guide dump.
**Cost**: 45,080 output tokens reported for the oversized call; downstream recovery cost unknown.
**Suspected cause**: Broad metadata printing treated connector descriptions as short summaries despite their repeated full manuals.
**Proposed change**: none — filter by exact tool name, print names for discovery, and return only the declaration suffix when schema inspection is necessary. Do not add resident instructions for this one observed misuse.
