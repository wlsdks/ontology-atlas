**Observed**: A chain `pnpm desktop:build:app:local && pnpm desktop:deploy:app` built the app twice; the deploy step's own build first cleaned the bundle the previous step had just produced.
**Cost**: unknown; a second full app build, estimated at 4 minutes.
**Suspected cause**: `scripts/deploy-macos-app-local.mjs` builds unless `--skip-build` is given.
**Proposed change**: none: run `pnpm desktop:deploy:app` alone, or pass `-- --skip-build` after a separate build; revisit if it recurs.
