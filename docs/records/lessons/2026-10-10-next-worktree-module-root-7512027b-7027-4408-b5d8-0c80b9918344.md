**Observed**: `pnpm dev --port 4321` in the isolated worktree failed with `Symlink [project]/node_modules is invalid, it points out of the filesystem root`. A fallback to `next dev --webpack --port 4321` then failed on the existing `mcp/src/analysis-history/name-page.mts` TypeScript syntax. Replacing only the worktree's node_modules symlink with `pnpm install --offline --frozen-lockfile --ignore-scripts` allowed Turbopack to render the unchanged baseline route.
**Cost**: two failed server starts and a misleading initial browser error state; elapsed time was not measured.
**Suspected cause**: the symlink crossed Turbopack's root boundary, while the fallback bundler did not share its configured .mts handling.
**Proposed change**: rule — prepare each isolated Next worktree with its own package-manager linked node_modules tree; check the installed guide and existing module formats before choosing a bundler fallback. Preserve the shared source tree and lockfile.
