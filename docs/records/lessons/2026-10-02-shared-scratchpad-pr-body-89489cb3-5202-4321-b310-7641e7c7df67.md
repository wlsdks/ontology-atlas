**Observed**: `gh pr create --draft --body-file <session scratchpad>/pr-body.md` opened #2283 (`design/harness-empty-preview`) with the description of a parallel subagent's first-run pull request (#2281). The session scratchpad is shared by every subagent of the session, and the sibling wrote its own `pr-body.md` there between my write (13:31) and my `gh pr create` (13:42). `gh pr edit 2283 --body-file /Users/jinan/scratch/harness-empty/pr-2283-body.md` restored the right description.
**Cost**: one draft pull request public with another change's description for about five minutes.
**Suspected cause**: generic file names (`pr-body.md`, `commit-msg.txt`, `change.txt`) in a scratchpad that parallel subagents share, with nothing that namespaces them per task or checks the file before it is sent.
**Proposed change**: skill — `/parallel-brief` tells each subagent to keep message and body files in a folder named for its branch (for example `<scratchpad>/<branch>/pr-body.md`) and to read the file back before `gh pr create` or `git commit -F`.
