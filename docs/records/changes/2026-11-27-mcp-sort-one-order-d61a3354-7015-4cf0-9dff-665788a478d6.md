Lists with Hangul and Latin names now sort the same everywhere. The MCP server's concept list, graph queries and maintenance output used to follow the language of the terminal that launched it, so a Korean terminal put Hangul names first while the app and an English terminal put them last. Everything now uses one English-collation order: Latin first, Hangul after. People who launched the server from a Korean terminal will see their lists reorder once, and a connected project source's stored graph hash may re-measure once.
