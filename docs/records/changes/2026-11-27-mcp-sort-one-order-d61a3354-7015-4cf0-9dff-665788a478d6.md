The MCP server's lists and the graph and analysis digests Atlas stores no longer change with the language of the terminal that launched it. A Korean terminal used to put Hangul names before Latin ones while the app and an English terminal put them after, so the same vault produced two orders and two digests. Every list and digest now uses one English order: Latin first, Hangul after. People who launched the server from a Korean terminal will see their lists reorder once. A project source whose names mix Hangul and Latin reports "ontology changed" once and asks to be measured again, although nothing in the vault changed.
