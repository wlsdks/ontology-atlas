API keys and local model runners moved from Settings to a Models tab on the Agents page (Agents, Models, MCP). Ollama, LM Studio and llama.cpp each have a row at their default address that says whether the runner answered, had no models, or could not be reached after you press Check; keys can be added, checked, replaced and removed there, showing only their last four characters. The tab also counts every transfer recorded in the open folder. Settings keeps one Models row that takes you there, and the map's "add a key" button opens the tab directly.
