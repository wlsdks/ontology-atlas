The Harness screen now opens on Setup, which lists what an agent reads in the connected repository, what stops it before it acts and what checks its work afterwards: instruction files, rules, skills, subagents, MCP config and ignore files; permission rules and blocking hooks; hooks, scripts, Git hooks and CI workflows, each by its real name with a filter per agent tool. A problems strip names only a hook script a config names but the disk lacks, or an AGENTS.md over Codex's default 32 KiB limit, and opens the file concerned; a Claude or Codex copy that differs from its twin is marked on the file, not as a problem. The At a glance domain table, its gap request and the separate Guides view are gone; old Guides links open Setup.
