Work status shows each Claude Code session in a room on a line of its own, with the name Claude Code gives the session, so it can be matched to the terminal or window it runs in. The line says the session's state and for how long, and a waiting session comes first. Names stay in memory only, never in a file, log or agent, and Show session names in the reads panel turns them off.
