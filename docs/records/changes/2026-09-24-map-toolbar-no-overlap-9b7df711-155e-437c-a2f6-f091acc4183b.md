The map's top toolbar no longer draws its buttons on top of one another. With the meaning-review panel or the agent dock narrowing the map, the search tools, a path and the trail used to slide under the buttons on the right; now the row keeps every button whole, moves the search tools to a second line when both groups do not fit, and shortens the path's name instead (the full name is on hover). The mascot button now has the same square as the rest of the row, and every button in the row is spaced the same.
