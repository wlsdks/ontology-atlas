The Library's Sources home is easier to read. Under the write button it names the connected agent that writes the pages, and the next-to-write panel says that Atlas sends your sources nowhere, and that an agent you give a page to write or a question reads the sources it needs, which may be sent to that agent's service. A source that changed after its wiki page was written is now called that instead of "needs review", and pressing it lists exactly those sources. The chart title is no longer cut off. Wiki pages are drawn as lighter written paper, apart from sources; file pictures are smaller with more room between rows; the next-to-write list marks only unusual states; each recent page shows its date beside its source; and the buttons above the file list are one main button and two quieter ones, none cut off.
