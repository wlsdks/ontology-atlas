The Library graph is now a flow picture: sources stand in a column on the left, the pages written from them in the middle level with the files they cite, and the concepts those pages name on the right, with the lines running left to right as S-curves. The same folder draws the same picture on every visit and every machine. A long folder lays itself out as a taller list the camera fits; past an 18px row a column of pages folds into sub-columns with room for every name, and a folder of hundreds of files folds its file band into a grid that names a file on hover or zoom. File names stand left of their squares, page and concept names right of their discs. Dragging a mark now moves the whole picture; the legend under the canvas says what stands where.
