Work status, in the macOS app, shows how much memory and CPU each room's agent and the commands it started use, grouped by program, and this Mac's memory, CPU and GPU use. The header warns when memory runs low or CPU or GPU stays full. Atlas reads program names only, never command lines, and nothing leaves the Mac. Read memory, CPU and GPU use in the reads panel turns it off.
