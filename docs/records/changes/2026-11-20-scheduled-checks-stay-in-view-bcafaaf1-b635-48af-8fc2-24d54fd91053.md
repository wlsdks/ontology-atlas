A scheduled check now stays in view on every screen while it runs. The card in the corner names the schedule, the document it is checking and how many documents it has checked so far, and its Stop ends that run while the schedule stays on. The Automations tile shows a ring while a check runs and counts the finished runs until you open Automations, where the running check has its own stage. A check that finishes elsewhere turns the card into its result, with Open run leading to that run in its history; when the wiki check and a scheduled check run at once, "1 more running" opens a list of both.
