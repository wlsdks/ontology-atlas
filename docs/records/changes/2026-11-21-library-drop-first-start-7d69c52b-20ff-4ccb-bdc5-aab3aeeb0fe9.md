An empty Library now starts with the documents you already have. Files in the open folder but outside the sources folder come first, with a count per folder and Copy all into the sources folder, or Choose files to copy. Below them, drop files or whole folders anywhere on the window, or press Add files: they are copied into the sources folder with their folders kept, and the originals are not moved or deleted. A drop of 500 files or 500 MB asks first; copying runs in the background with progress and Stop copying, and then the Library says how many files it did not copy and why, with their names. Markdown files can now be added too, except those the ontology uses. The stage names the sources folder and, in the app, offers Show in Finder.
