Connecting a project source and reading its structure now take in up to 16,000 files instead of 8,000, in the app and through MCP alike. A repository between those sizes, this one included, is read whole instead of being cut off, so its file counts and the files Atlas can cite are complete. A repository past 16,000 files is still cut off at that bound, and the result still says so.
