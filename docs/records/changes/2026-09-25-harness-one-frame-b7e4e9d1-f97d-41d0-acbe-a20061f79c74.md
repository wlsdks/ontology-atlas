The Harness screen now reads as one page. Every view starts on the title's line and keeps the 1600px page width that other screens use, so wide windows add margin instead of stretching the content. Each data view opens with the same label, one sentence of what was found, and the rule it was counted by. Structure gets its own sentence, and the note that its numbers are not runs or scores appears once. Text in the Structure, Coverage and Guides views moves from 9.5px up to 11px. Guides rows share one height, and only a real difference between a pair wears a tag. Coverage chevrons sit beside their counts, and the answer columns now span the table instead of crowding its right edge. The agent loop is explained once, in its own card. The Architecture toolbar uses the standard control height.
