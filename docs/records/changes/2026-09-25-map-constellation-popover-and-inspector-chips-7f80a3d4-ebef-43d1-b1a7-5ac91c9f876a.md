The map's constellation popover now hangs from its own button and stays in the free map, so it no longer covers the INDEX panel or its folded tab at any width. A vault that has never saved a constellation, or holds an empty constellations file, opens to the empty state instead of "could not read your saved constellations", and a failed save no longer relabels the list as a read failure. When a read does fail, the notice is a readable card with one Reload action, and Create is either pressable or says why it is not. In the node inspector the kind chip, the domain chip and the close button share one 32px chip height, radius and type size and end on one right edge.
