A project is drawn by its locale display name (`display_<locale>`) on every screen that names it: the projects list, the project page's heading, breadcrumb and document title, the map drawer, the map's path chips and both search palettes. The map, the INDEX and the Library already did; the list and the page said the canonical title beside them. Editing the heading in place edits the word on screen: the display key when one exists, the canonical name otherwise. Search matches the canonical name and every display name.
