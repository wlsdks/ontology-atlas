Writing wiki pages, fixing a page, bringing sources in, proposing a concept, or a request you type in the Library conversation now keeps running when you go to another screen. The card in the corner names what was asked, the file the agent is writing and how many files it has written. When the agent asks for permission the card says what it wants to change, and Review opens the Library conversation at that request; nothing answers it for you. Stop refuses every later request and ends the agent if it has not stopped in 5 seconds. When the work finishes elsewhere the card says which files were written, with Open the page for a single page. A conversation opened on the map or a project for the same folder waits until the Library's work ends.
