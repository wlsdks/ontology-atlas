A connector or Library round that a folder arrives with switched on, whether cloned, synced or pulled, no longer attaches or runs until this Mac allows it. The MCP tab and Automations list each waiting item with everything it would run and one press to allow it, and ask again when the folder changes it. After this update, connectors and rounds switched on before wait for that one press each. A connector can use only its own keychain entries.
