The agent chat's mode picker has an "Auto-approve" choice. Asking before every write stays the default; "Auto-approve" lets file edits inside the opened folder and adding or changing concepts and relations go ahead without a permission card for the rest of that conversation, each one leaving an "Auto-approved" line in the transcript. Shell commands, anything outside the folder, hidden files such as `.git/`, deletions, merges and commits still ask, and every new or resumed conversation starts back at asking.
