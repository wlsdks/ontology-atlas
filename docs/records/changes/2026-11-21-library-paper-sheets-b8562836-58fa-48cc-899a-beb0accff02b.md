The Sources home now draws files and wiki pages as small sheets of paper. Each file in the "next to write" list carries a folded sheet with its format written on it (PDF, CSV, PPTX and so on), and while a page is being written from a file, a line slowly scans down that file's sheet. Each page in "Recently written" is a written sheet with a tab naming its source's format, with the title on the first line and the file it came from under it. With reduced motion on, the file being read is tinted and the scan does not move.
