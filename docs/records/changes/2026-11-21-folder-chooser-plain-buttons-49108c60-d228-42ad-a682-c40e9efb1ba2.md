On the folder chooser, the button for making a new folder is called Create folder and no longer carries a down arrow; it still opens the same short list of ways to create one, and Escape returns to it. In Korean, the Documents choice now names the Documents folder as the Korean Finder shows it, and the review of folders that can no longer be found says the folders leave the recent folders list. In the folder switcher on the left rail, the line for folders that can no longer be found now opens the same centred review as the folder chooser instead of growing in place, and closing it returns to the folder button on the rail.
