The Library's Ontology, Work scope and Check history tabs read as one family. Check history opens with Work scope's headline and column and keeps one way to Automations; before anything is scheduled it shows one button to schedule a check beside the two kinds it can run, and the four results a run can leave. The away card no longer repeats the sleep gap the run list shows, and the help card beside the checks no longer pushes their names out of view. A run with no change reads "no change" in both languages. Work scope's empty state previews six concepts with their map glyphs and ends in "N more, see them all on the map". A document's meta row keeps one control height, and its properties line names the kind in words, not YAML. Every tab switch, Sources and Wiki included, fades the panel in, with reduced motion too, and run times over a minute read in minutes.
