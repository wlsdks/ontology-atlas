The Library's Ontology, Work scope and Check history tabs read as one family. Check history now opens with the same headline and centred column as Work scope, says "nothing yet" once, keeps a single way to Automations, and draws its empty history as rows waiting to fill. Work scope's empty state starts right under the header, previews six concepts with their map glyphs instead of three inert radio circles, and closes with "N more, see them all on the map". Scope members read in full ink and line up with their folder's name, and a scope saved without a purpose no longer says so as if it were one. A document's meta row keeps every control at one height and sets Korean in the UI font. Switching tabs fades the panel in, and run times over a minute read in minutes.
