A large open folder now takes about half the memory, and a folder opens faster: each document keeps only its title, frontmatter, short first paragraph and the documents it links to, and its headings, excerpt and word count are read from the file when a screen shows them. The app's index no longer keeps a separate copy of each document's headings, excerpt, link text and the passages around its links, and Settings › Privacy · data says so. The first launch after updating reads every file of a folder once, because the index rows the earlier version wrote are not reused.
