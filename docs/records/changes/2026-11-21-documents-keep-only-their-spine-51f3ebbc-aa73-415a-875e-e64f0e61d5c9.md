A folder of 50,000 documents now opens in about half the time in the app and about a third faster on the web, and once open it holds about a third less memory in the app and less than half on the web: each document keeps only its title, frontmatter, short first paragraph and the documents it links to, and its headings, excerpt and word count are read from the file when a screen shows them. The app's index no longer keeps a separate copy of each document's headings, excerpt, link text and the passages around its links, and Settings › Privacy · data says so. The first launch after updating reads every file of a folder once, because the index rows the earlier version wrote are not reused.
