The Library's Sources home is now a table instead of a graph. Each folder (or file type) is one row with its number of sources, how many already have a wiki page, how many wait, and when its last page was written; beside it, a panel lists the next files "Write wiki pages for the next 10" will send, and while the agent writes, the files in progress stay at the top until their pages land. Pressing a row shows that folder's files and narrows the source list on the left to them, with a chip to clear it. The list marks each source that still waits with a small dot. The old picture of checkbox squares and the dotted island disc is gone. On a narrow window the panel moves under the table, and the band's sentence shows a tooltip only when it is cut off.
