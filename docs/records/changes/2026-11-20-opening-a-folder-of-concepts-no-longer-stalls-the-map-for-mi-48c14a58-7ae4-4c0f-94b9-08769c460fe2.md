Opening a folder in which every page is a concept no longer stalls the map for minutes. At 50,000 files the page used to stop answering twice while the map was placed, for about 56 and then 97 seconds; now it stops once, for about 18 seconds, and the folder finishes opening in about 36 seconds instead of 74. When only pages the map does not draw arrive, and when the folder settles, the map keeps the picture it has instead of placing everything again.
