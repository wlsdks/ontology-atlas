Changing a document's kind no longer leaves it in other documents' lists for its old kind: a domain that listed a capability lists it among its elements once that capability becomes an element, in the app whether or not the file moves, and through MCP reclassify_concept and merge_concepts. The quick edit names each document whose list changes before Save, and a notice names them after. When a document's own kind keeps no list for the new kind, the entry stays where it was and that document's page says so, as it now does for any entry sitting in a list for another kind.
