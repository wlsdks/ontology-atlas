Library now holds Sources, Wiki, and Ontology in one destination while keeping each file on disk as the source of truth. Markdown source headings open their cited lines, the Ontology tab starts with graph-backed documents and finds localized names or canonical paths, and legacy `/docs/?slug=…` links and unsaved drafts survive tab changes. Wiki creation previews the actual Markdown path and section structure in a centered dialog, the current work receipt stays separate from its history, and a successful app write produces one actionable notification instead of a duplicate folder-watch toast.
