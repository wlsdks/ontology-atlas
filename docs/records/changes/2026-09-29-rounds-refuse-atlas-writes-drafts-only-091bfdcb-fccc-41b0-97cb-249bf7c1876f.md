An unattended round that asks to change the ontology is refused at once and the refused tool is named in its run, instead of waiting out its twenty-minute limit; a page a document round writes lands only as a draft, judged as the agent's edit tool applies the write, against the page as that run's earlier writes left it, under any spelling of its path; after each run Atlas reads back every page it wrote and puts back, or removes if the run created it, any page its own write left that does not read as a draft, saving the text it takes out and naming the page and the reason in the run, while a page someone else changed during the run is left as it is; a round never writes over a file that carries kind:; and a service round can write the page for a document it brought in during the same run.
