A round refuses an ontology change at once and names the tool, instead of waiting out its limit. A document round writes only drafts, judged as the edit tool applies each write, against the page as earlier writes left it, under any spelling of its path, and never over a node, through a symbolic link, or into a folder it did not find. After each run Atlas puts back, or removes, any page its own write left that is not a draft, keeping the text it takes out and naming the page in the run; a page changed after the run wrote it is left as it is, failing the run if it is not a draft. A service round can write the page for a document it brought in during the same run.
