Atlas now uses a compass for app and platform icons and Moru, a gray pixel seal, for its character and activity slots. Moru's project catalogue contains fifty motions and sixteen static poses, including dancing, singing, friends, pups and weather scenes, with retained sources and an inspectable local preview. Existing welcome, pending and verified-completion states use the new artwork; reduced motion, permission boundaries and the quiet navigation rail remain.
