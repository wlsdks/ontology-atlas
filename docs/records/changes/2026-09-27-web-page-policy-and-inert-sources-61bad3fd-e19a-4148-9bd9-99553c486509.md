On the web, opening a Library source opens a copy only of a PDF, an image or plain text; an HTML, SVG or any other file is saved to downloads instead, because a copy opened in the page would run in the site's origin. A remote image in a page is no longer loaded: its place names the host and opens it in a new tab only when pressed. The production site now carries a Content-Security-Policy that refuses remote images, connections, plugins and form targets. Each program in the connector catalogue runs the version checked on its date, and its row says which.
