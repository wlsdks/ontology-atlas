On the Git screen, a step's "Concepts changed" no longer counts the vault README as a concept, and a document-kind mark no longer borrows the element's glyph. The default concepts lens now shows what the step wrote in the chosen concept's document, marked in place, above that document's other steps. After connecting a remote, the connect button stops saying "Connecting…" as soon as the address is saved and the header offers the branch's first send from that moment; a remote action's result is announced with the screen it describes, a sent save is reported in one sentence, and a failed send says git's reason.
