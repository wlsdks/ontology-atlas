On the Git screen, a step's "Concepts changed" no longer counts the vault README as a concept, and a document-kind mark no longer borrows the element's glyph. The default concepts lens now shows what the step wrote in the chosen concept's document, marked in place, above that document's other steps. After connecting a remote, the screen says it is connected but not sent yet and offers "Publish branch", which sends the branch once and pairs it so Fetch, Pull and Push work; the connect button stops saying "Connecting…" as soon as the address is saved, Push with nothing to save sends instead of doing nothing, and a sent save is reported in one sentence.
