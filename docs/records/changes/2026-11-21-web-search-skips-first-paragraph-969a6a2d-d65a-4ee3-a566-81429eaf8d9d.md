On the web, and in the app with the search index off, a plain page is found by its title, display name, slug, tags and description, and no longer by a word that only its first paragraph holds. A concept without a description is found by its definition preview. In the app with the index on, search still reads the whole text of every page. A project's related-documents list likewise stops counting mentions in a page's first paragraph.
