On the web, and in the app with the search index off, a plain page is found by its title, display name, slug, tags and description, and no longer by a word that only its first paragraph holds. A concept without a description is found by its definition preview. In the app with the index on, the documents palette still finds a page by its first paragraph when the page is among the index's 15 best files, and the Library's wiki list when the index matches it. A project's related-documents list likewise stops counting mentions in a page's first paragraph. A project without a description now shows its definition preview, so one whose opening paragraph is over 320 characters, or that starts with a list, has no fallback description.
