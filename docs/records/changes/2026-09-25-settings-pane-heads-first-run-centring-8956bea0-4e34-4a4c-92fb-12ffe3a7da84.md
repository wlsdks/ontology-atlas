Every settings pane now opens with its own heading and one sentence saying what it decides, and the side list is quieter so the settings it leads to come first. Row buttons share one size, the API Key pane has a key icon and its privacy note reads as one sentence, the Expand choices use the same joined switch as the Screen pane, and the Update row says when it could not read the version. The first-run screen centres its headline, keeps its three doors the same height, and uses larger text. On the download page, the release facts that wrap onto a second line now start at the same edge as the first.
