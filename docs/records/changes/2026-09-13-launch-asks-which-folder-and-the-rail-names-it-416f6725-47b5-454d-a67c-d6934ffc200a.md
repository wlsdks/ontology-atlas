When Atlas knows two or more folders on this computer, launching now asks which one to open instead of silently reopening the last. Each row says how many documents and concepts it held when it was last read, when that was, and whether it can be opened right now; a folder that has been renamed, moved, unmounted or refused says so before it is pressed rather than failing after. One known folder still opens directly, and dropping a folder from the list is what returns a launch to opening directly, so there is no setting to find. Whichever way the launch went, the open folder's name now sits at the top of the rail on every destination, and pressing it opens the same list plus a picker for a folder Atlas has not seen.
