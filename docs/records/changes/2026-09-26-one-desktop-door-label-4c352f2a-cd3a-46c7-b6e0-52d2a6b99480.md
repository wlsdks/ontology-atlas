The web's door to the desktop app now carries one label everywhere, "Get the app" and its one Korean equivalent, instead of four, and the sentences beside it call it "the desktop app" (the download page offers macOS and a Windows beta, so "Mac" was not true); the line saying Windows was still coming is gone. The longer "Get the desktop app" was tried first and did not fit the phone tab bar: it wrapped onto two lines, lifting that tab's icon out of line, and at 200% text it pushed the bar past the room pages reserve for it. Every Button wears the chip corner, so a 40px primary no longer reads as a pill. The dogfood vault's ten concepts whose code changed were re-read and updated, and a leftover empty `dependencies: []` was removed.
