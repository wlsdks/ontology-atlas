The Projects destination now presents a compact index built for choosing a project: each row shows the linked project name, its explicitly authored one-line purpose, a recent update, and clearly labelled actions for details and the map. Graph counts, domain composition, recent document activity, and CLI or agent creation instructions no longer compete with project selection; project composition, editing, and construction review remain on the detail page.
