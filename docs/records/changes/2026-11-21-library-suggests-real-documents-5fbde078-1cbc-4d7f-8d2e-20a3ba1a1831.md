When the Library is empty and suggests files it found in your folders, it no longer offers licence and notice files (such as LICENSE.txt, NOTICE.txt or third-party-licenses.txt), files named only by a long code like 39b8c5bebbe326f89097083d57514dcc.txt, files under 64 bytes, build files such as CMakeLists.txt, requirements.txt and robots.txt, or anything inside published, generated, output, cache, log, third-party and test-data folders (public, static, output, generated, tmp, logs, fixtures, src/test/resources, tests/data and similar). Real documents such as a budget spreadsheet or a scanned PDF named by its date are still suggested, and you can still add any file yourself.
