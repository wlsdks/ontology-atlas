In the installed app, Escape closes the palette, sheets and dialogs under every macOS input source: the app notices each Escape press itself and hands the page the one keypress a Korean input source can keep from it, never a second one when the page already has it. The settings sheet takes focus when it opens by a click, so Escape and Tab work at once, and a click on the dim beside it closes it. The Git screen tells three states apart instead of saying there is no remote: with no remote it still offers to connect one; a branch never sent to an existing origin gets a one-press first send that records where it goes; a detached HEAD names the commit and says sending needs a branch. Nothing on that screen can replace an existing origin any more, and Push with nothing new to commit now sends the commits already made.
