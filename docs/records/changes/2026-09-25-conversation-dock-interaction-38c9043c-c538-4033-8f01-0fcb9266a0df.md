The agent conversation dock no longer draws its tool and mode pickers over the status word on a narrow dock, and its buttons share one size. Escape keeps a typed sentence on the map and in the Library alike, and a sentence put away on the map is still there when the dock opens again. After Stop, New conversation or a permission answer, focus is in the composer, and the Library dock returns focus to its door. You can type while the tool connects. A write you declined says so instead of "failed", and tool rows no longer show a function name. On short windows the permission card leaves the call it asks about in view, the close button stays in the corner, and a failed save shows one sentence with the detail folded.
