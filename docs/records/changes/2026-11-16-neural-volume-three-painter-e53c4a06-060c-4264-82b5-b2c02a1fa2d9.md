Neural now reads as a volume. Each domain's cluster stands at its own depth instead of on a ring, and where the browser has hardware WebGL2 the concepts are lit spheres that hide what is behind them, with a faint shell round each cluster; elsewhere the earlier flat drawing shows the same map. Turning it sideways keeps the whole map on screen, with or without a selection; tilting it up or down is not followed. Names no longer run under an open panel.
