The Library's Korean tab names now say what the tabs hold. The Collections tab's Korean name reads "work scope" (a set of concepts saved from the galaxy for one piece of work) instead of a bare "collection", and the Rounds tab's reads "automatic check" (the checks the app runs on a schedule while it is open) instead of a word for "patrol"; one pass of a check is called a "run" rather than a "round". English names are unchanged.
