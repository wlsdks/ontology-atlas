The in-app agent chat keeps three choices per folder on this Mac: Auto-approve, the tool and the model. A folder where Auto-approve was chosen opens every later conversation on it, on any screen and after a restart, until a mode is picked or the folder is forgotten under Settings → Privacy · data, which now lists "Chat auto-approve" beside the MCP servers and scheduled checks allowed for each folder. The kept choice is stored in the app, never in the folder, applies only to the exact set of writes it was given for, and is never used by unattended scheduled checks.
