The in-app agent chat shows the turn at work from the moment a request is sent: Moru acts the kind of work the agent reports (thinking, reading, searching, writing, running a command, typing the answer), the line under it names the call in flight and its file or concept, and a bar shows the agent's reported plan or, without one, a sweep and the number of calls so far. A finished turn gets one dance and "Done", then the stage folds away.
