In the installed app, the line under the Wiki question field now names the folder's search-by-meaning model in a Model chip. It opens one dialog that lists the built-in bge-m3 and every allowed Ollama embedding model, states the chosen one's size, where it is kept and what it sends, and downloads, switches or deletes it in place. Delete takes one press under a sentence naming the space freed and that every folder using the model searches by words until it is downloaded again; Open its folder shows the model in Finder or Explorer. While a folder prepares, the dialog offers Stop instead of a switch. Settings › Privacy · data still deletes the model too.
