The map has a new view, Territories, in the view picker next to Flat. It draws every capability by name around its own domain, with nothing to expand: a capability's circle grows with its elements, an amber ring marks one whose cited code changed after its document, and each domain's title counts its capabilities, elements and stale ones. Strokes between domains count how many of their capabilities depend on each other. Selecting a capability opens the usual inspector and shows its elements and its own dependencies. The desktop app reads stale from Git; the web says the state is unknown instead of guessing. A link with `?view=territories` opens the view.
