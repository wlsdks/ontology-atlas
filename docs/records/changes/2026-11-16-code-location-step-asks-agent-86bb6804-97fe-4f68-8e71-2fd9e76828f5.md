When a project has no recorded code locations, the map's project panel now says so in plain words and its button does something: with an in-app agent ready, "Ask the agent" opens the chat with a request to find each capability's and element's file and record it; otherwise "Copy the request" copies that request for your own agent. Before, "Link code location" only reopened the project's detail, where the same button did nothing.
