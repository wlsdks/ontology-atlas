# RATIO-SYSTEM — 화면 비율 규범 (final mockup round, 2026-07)

> 지상 원칙: **비율이 생명.** 1920×1080 프레임 전체에서 세로·가로 여백이
> 아름다운 비율로 균형을 이룬다. 상단에 콘텐츠가 몰리고 하단 1/3 이 죽는
> 구조 금지. 이 문서는 규범(normative)이며 구현 시 DESIGN-SYSTEM v2 에
> 토큰으로 승격된다. 모든 `*-final.html` 목업이 이 시스템을 따른다.

## 1. 가로 — 단일 거터 시스템 (앱 전체 통일)

- **페이지 컨테이너 `1600px` 중앙 정렬** → 1920 에서 좌우 거터 **160px**
  (콘텐츠 83.3%). 이전 라운드의 1240/1440/1640 혼재를 폐기한다.
- 내부 좁은 컬럼은 컨테이너 안에서 중앙: 리딩 컬럼 **1200** · 유틸리티 페이지
  **960** · 폼 **640**. 좌우 대칭이므로 거터 리듬은 유지된다.
- **풀블리드 예외는 지도 서피스뿐** (topology): 캔버스 엣지-투-엣지,
  플로팅 패널 마진 18px (기존 계약 유지).

## 2. 세로 — 945 프레임 리듬

- 유효 뷰포트 = **945px** (1080 − 메뉴바/브라우저 크롬 ~135, 기존 프레임
  표준과 동일). 페이지는 945 안에서 **완결 구도**로 조판한다.
- 상단 오프셋 **32px** → 헤더 존(크럼스+타이틀+census) **≤ 130px** →
  탭 바 → 콘텐츠 존 → 하단 호흡 **40px**.
- 콘텐츠 존은 상/하 시각 무게 **~55/45**. 하단 데드스페이스 **≤ 15%**
  (>30% 절대 금지). 장치: 페이지 = flex column, 주 콘텐츠 `flex: 1`,
  마지막 행(핸드오프/푸터)은 `margin-top: auto` 로 하단 근처에 앵커.
- 리듬 상수: 섹션 갭 **28px** · 카드 갭 **20px** · 카드 내부 패딩 **16px**
  (구 13–14px 에서 상향 — 1920 판독 스케일).
- 한 화면에 다 안 들어가면 **탭으로 분리한다** — 세로 스크롤로 비율을
  깨느니 탭 구도 2~3장이 낫다 (insights · 상세류).

## 3. 탭 바 — 단일 패턴 (machined)

- 위치: 페이지 헤더 바로 아래, 전폭 hairline(divider) 위.
- 탭 = mono tracking-caps 라벨 + 음각 카운트 숫자.
  - active: **2px 인디고 underline** + `text-primary`
  - inactive: `text-quaternary`, hover `text-secondary`
  - 예정/비활성: **dashed underline** (헌장 — 카테고리 구분은 보더 스타일)
- 색 배지·필 배경 금지. underline 이 유일한 상태 표식.

## 4. 데이터시트 스케일업 (토폴로지 우측 패널)

"정보는 좋은데 너무 작다" 반영 — 1920 판독 기준으로 한 단계 상향:

| 항목 | 구(B3/E) | 신(final) |
|---|---|---|
| 패널 폭 | 288px | **352px** |
| 타이틀 | 13.5px | **15px** |
| 행 | 12px | **13px** |
| 메트릭 | 11.5px | **12.5px** |
| 행 패딩(세로) | 4px | **6px** |
| 그룹 갭 | 10px | **14px** |
| 패널 패딩 | 11px | **14px** |

INDEX 폭 300px 은 유지 — 좌 300 / 지도 / 우 352 의 비대칭이 지도 중심을
좌로 살짝 밀어 시선 균형을 만든다.
