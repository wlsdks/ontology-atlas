Product Owner Operating System

기능·UX·그래프·MCP·CLI·워크플로 변경 전에 적용하는 필수 PO 게이트. 관찰된 현상과 사용자 문제에서 출발해, 온톨로지 가치·에이전트 가치·단순화·검증 계획을 명명한 뒤에만 구현에 들어간다.

  • 산출물이 아니라 결과 — shipped output 은 워크플로 개선일 때만 진전으로 친다
  • 솔루션 요청 번역 — "X 추가해줘"는 관찰 가능한 문제로 먼저 환원
  • 판정으로 끝맺기 — Do not build · Investigate first · Shape a slice · Build and verify

이 문서 자체가 vault 의 capability 노드다 — 코드 근거는 evidence 관계로 docs/PRODUCT-OWNER-OPERATING-SYSTEM.md 에 연결되어 있다.
