vault 폴더 선택

첫 실행이 로컬 마크다운 폴더를 묻습니다. 그 폴더가 곧 온톨로지입니다.

Developer ID 서명 codesign --verify 통과
Apple 공증 (notarized) + stapled ticket xcrun stapler validate 통과
spctl --assess --type open --context context:primary-signature Ontology-Atlas_0.1.0_aarch64.dmg

서명·공증은 릴리스 CI 에서 수행되고, 검증 명령과 체크섬은 GitHub Release 노트에 그대로 공개됩니다. 보안 주장은 구현 공개 + 재검증 가능일 때만 합니다.
