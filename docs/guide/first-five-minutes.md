# 첫 5분

## 설치 없이 먼저 보기

브라우저에서 바로 열 수 있습니다. 마크다운 폴더를 고르면 그 자리에서 지도가
됩니다. 폴더는 브라우저 밖으로 나가지 않습니다.

파일 시스템 접근이 필요해서 **Chrome · Edge · Safari 18.2+ · Opera** 에서
동작합니다. Firefox 는 아직 이 API 가 없어 폴더를 열지 못합니다.

## 앱으로 쓰기

macOS 앱이 볼트의 본거지입니다. 브라우저가 원리적으로 할 수 없는 일들이 앱에만
있습니다.

| 능력 | 앱 | 웹 |
|---|---|---|
| 볼트 절대 경로 | ✓ | 핸들만 (경로 없음) |
| git 기록·스냅샷 | ✓ | 불가 |
| API 키 보관 | OS 키체인 | 원리적 불가 |
| 폴더 감시 | OS 워처, 0.5초 | 폴링, 1.5~5초 |
| MCP 서버 | 앱에 동봉 | 소스 체크아웃 필요 |

앱이 처음 묻는 것은 폴더 하나입니다.

## 처음 열면 무엇이 보이나

빈 폴더를 고르면 시작 노드 다섯 개가 생깁니다. 이미 문서가 있는 폴더라면
frontmatter 가 있는 파일이 곧바로 노드가 되고, 없는 파일은 그냥 문서로 남습니다.

**아무것도 망가뜨리지 않습니다.** Atlas 는 파일을 옮기거나 이름을 바꾸지 않고,
frontmatter 를 읽을 뿐입니다. 마음에 안 들면 폴더를 닫으면 끝입니다.
