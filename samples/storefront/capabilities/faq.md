# FAQ · 자주 묻는 질문

「배송은 며칠 걸리나요」처럼 가만두면 1:1 문의로 한 건씩 도착할 질문에, 미리 답을 적어 두는 게시판입니다. 상담원이 개입하지 않으니 가장 값싼 고객 지원입니다.

여기 실을 기준은 하나입니다: 같은 질문이 반복해서 들어오는가. 반대로 특정 주문에 대한 질문은 아무리 흔해도 여기 답이 없습니다. 그런 질문의 자리는 1:1 문의입니다.

Answers in advance the questions that would otherwise arrive one by one as tickets, which makes it the cheapest support there is. Only questions that repeat belong here; anything about a specific order belongs in a one-to-one inquiry.
