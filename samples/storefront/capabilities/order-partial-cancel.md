# Partial Cancellation · 부분 취소

Drops some items and keeps the rest alive, so only the difference is refunded and the remaining parcel still ships.

일부 품목만 빼고 나머지 주문은 살려 둡니다 — 차액만 환불되고 남은 상품은 그대로 출고됩니다.
