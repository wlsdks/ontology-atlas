# Order Status Log · 주문 상태 이력

주문이 접수부터 지금까지 거쳐 온 상태를 시각과 함께 쌓아 둔 이력입니다. 고객이 「내 주문 어떻게 됐지」 하고 열어 보는 화면도, 상담원이 전화를 받으며 보는 화면도 결국 이것을 읽습니다. 현재 상태 하나만 저장하고 지나온 이력을 버리면, 「언제 결제됐고 언제 출고됐나」라는 가장 흔한 질문에 답할 수 없게 됩니다.

Every state the order has been in and when, which is what both the shopper and support actually read. Storing only the current state would leave the most common question, 'when did it ship', unanswerable.
