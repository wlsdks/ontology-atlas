# Search Index · 상품 검색 색인

검색창에 친 낱말이 상품을 빨리 찾을 수 있도록, 상품 글을 검색에 맞는 모양으로 다시 배열해 둔 사본입니다. 원본은 어디까지나 상품 정보 쪽이고, 상품이 바뀌면 이 사본은 다시 만들어집니다. 그 갱신이 늦으면 품절된 상품이 검색에 계속 나오거나 새 상품이 검색에 안 잡히는, 사본이 원본보다 낡은 문제가 보입니다.

A rebuilt-on-change copy of product text arranged so a typed word can find it fast. When the rebuild lags, sold-out products keep appearing in search: the copy has gone staler than the original.
