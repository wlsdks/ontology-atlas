# Stock Snapshot · 재고 스냅숏

어느 시점의 수량을 얼려 둔 것입니다. 「그때 몇 개였나」를 원장을 처음부터 다시 훑지 않고 답하려고 둡니다.

The count frozen at a moment, used to answer 'what did we have then' without replaying the ledger.
