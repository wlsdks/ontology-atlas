# Recommendation Rule · 추천 규칙

The stated reason a product is shown next to another one — bought together, same category, viewed after.

어떤 상품을 다른 상품 옆에 보여 주는 이유를 적어 둔 것 — 함께 구매, 같은 분류, 다음에 본 상품 등입니다.
