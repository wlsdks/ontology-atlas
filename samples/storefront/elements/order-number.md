# Order Number · 주문번호

고객이 전화로 불러 주는 그 번호입니다. 상담원이 받아 적고, 문자 알림에 찍히고, 영수증에 인쇄됩니다.

사람의 입과 귀를 거치는 번호라서 짧아야 하고, 0과 O처럼 헷갈리는 글자가 없어야 합니다. 가게 안에서 기록끼리 잇는 긴 번호는 따로 있어도, 사람에게 보여 주는 번호는 이 하나입니다.

The identifier a shopper reads out on the phone, which is why it must be short and unambiguous. Whatever the store uses internally, this is the one number a person ever sees.
