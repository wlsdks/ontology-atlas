# Stock Ledger · 재고 원장

재고의 모든 늘어남과 줄어듦을 한 줄씩 남긴 기록입니다. 「지금 몇 개인가」는 어딘가에 저장된 숫자가 아니라 이 기록을 합산한 결과입니다. 입고도 출고도 조정도 전부 여기로 모이기 때문에, 수량이 이상할 때 언제부터 어긋났는지를 되짚을 수 있는 곳도 여기뿐입니다.

The running record of every increase and decrease, from which the current count is derived rather than stored. When a count looks wrong, this is where you trace back to the moment it went wrong.
