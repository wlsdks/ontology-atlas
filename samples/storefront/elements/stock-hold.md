# Stock Hold · 재고 홀드

A short-lived claim on units for an order in progress; it expires by itself if the order never lands.

진행 중인 주문 몫으로 잡아 둔 짧은 예약이며, 주문이 성립하지 않으면 스스로 풀립니다.
