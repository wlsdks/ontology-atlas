# Referral Code · 추천인 코드

「친구 초대」에서 만들어지는, 새 고객을 데려온 기존 고객과 묶어 주는 표식입니다. 가입 화면에 이 코드가 입력되는 순간 두 사람이 연결되고, 초대 보상이 누구 몫인지가 정해집니다. 이 연결이 틀리면 보상이 엉뚱한 사람에게 가므로, 코드는 서로 겹치지 않게 만들어지고 한 번 맺어진 연결은 바꾸지 않습니다.

The token that ties a new customer back to the existing one who brought them. Codes never collide and a link, once made, is never rewired, because the reward follows the link.
